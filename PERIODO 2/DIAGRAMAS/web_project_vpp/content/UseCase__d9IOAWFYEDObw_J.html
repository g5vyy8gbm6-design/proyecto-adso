ESTABLECIMIENTO DUEÑO
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al panel de administración y navega a la sección "Gestión de Servicios".
    • Localiza el servicio objetivo y activa/desactiva el interruptor de estado.
    • El sistema solicita confirmación para cambiar el estado a Inactivo/Activo.
    • El usuario confirma la acción.
    • El sistema actualiza el registro y refresca la vista del catálogo.
■ Business Logic //LOGICA DE NEGOCIO
    • La inactivación de un servicio no afecta ni cancela las citas que fueron agendadas previamente mientras el servicio estuvo activo.
    • Un servicio en estado "Inactivo" no aparecerá disponible durante la selección de servicios en el flujo de reserva de clientes
    • El cambio de estado es inmediato y se puede revertir en cualquier momento.
■ Decisions //DECISIONES
    • Si un servicio inactivo tiene citas pendientes, el sistema desplegará una advertencia recordando que las citas programadas previamente aún deben ser atendidas o gestionadas.

(DESACTIVACIÓN / INACTIVACIÓN DE UN SERVICIO)
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a la sección "Catálogo de Servicios"
2. Selecciona un servicio activo de la lista y presiona el botón o switch "Inactivar / Deshabilitar".
3. El sistema consulta las reservas futuras agendadas que incluyen dicho servicio.
4. El sistema evalúa si existen compromisos pendientes asociados al servicio:
    4.1. if existen citas confirmadas o pendientes en el calendario asociadas a este servicio específico:
        4.1.1. El sistema muestra un mensaje de advertencia de confirmación: "Existen [N] citas agendadas con este servicio. Las citas previas se mantendrán en la agenda, pero el servicio dejará de estar disponible para nuevas reservas".
        4.1.2. if el propietario cancela la operación:
            4.1.2.1. El sistema interrumpe el proceso y mantiene el servicio en estado Activo.
        4.1.3. else if (El propietario confirma la desactivación):
            4.1.3.1. El sistema cambia el estado del servicio a Inactivo, retira la opción del catálogo público de la sede y deshabilita su selección en el motor de agendamiento para clientes.
        4.1.4. else if (No existen citas pendientes asociadas):
            4.1.4.1. El sistema inactiva el servicio de forma inmediata y actualiza el catálogo del negocio.
               end if
         end if

(REACTIVACIÓN DE UN SERVICIO)
Steps
1. El Dueño de Establecimiento accede al filtro de "Servicios Inactivos" dentro de su catálogo de servicios.
2. Selecciona un servicio en estado Inactivo y presiona el botón "Activar / Habilitar".
3. El sistema evalúa la configuración técnica del servicio:
    3.1. if el servicio no cuenta con al menos un Personal / Barbero asignado (RF28/RF30) O su precio registrado es cero:
        3.1.1. El sistema frena la activación y notifica "No se puede activar el servicio. Asigne al menos un colaborador capacitado y asegúrese de que el precio sea válido".
    3.2. else if
        3.2.1. El sistema cambia el estado del servicio a Activo, lo publica nuevamente en la ficha detallada de la sede y habilita la oferta de turnos para los clientes.
         end if
