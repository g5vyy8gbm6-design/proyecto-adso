Use Case - VISUALIZAR EN MAPA link

Properties
Name Value
Description

 

El sistema despliega una interfaz de mapa interactivo donde se ubican los marcadores o pins de los establecimientos registrados y activos en la plataforma.

El cliente puede interactuar con el mapa (hacer zoom, desplazarse o hacer clic en un marcador) para visualizar una vista previa rápida del local (nombre, foto, dirección y calificación) y acceder directamente a su perfil de reservas.

 VISUALIZAR EN MAPA : Use Case

CLIENTE
■ Workflow // Write
    • Accede al módulo de exploración y selecciona la opción "Ver en Mapa".
    • El sistema carga la API de mapas y ubica la posición actual del cliente o la ciudad seleccionada.
    • Se renderizan los marcadores con la ubicación geográfica (latitud/longitud) de los establecimientos disponibles.
    • El cliente presiona sobre un marcador específico.
    • El sistema despliega una tarjeta de vista previa con la información básica del local.
    • El usuario hace clic en la tarjeta para navegar al perfil completo del negocio.
■ Business Logic //LOGICA DE NEGOCIO
    • Solo se muestran marcadores de establecimientos cuya cuenta se encuentre en estado "Activo" y tengan una ubicación/sede validada
    • El mapa agrupa marcadores cercanos (clustering) cuando el nivel de zoom es lejano para evitar la saturación visual de la pantalla.
    • La ubicación de los marcadores se sincroniza en tiempo real con la base de datos geográfica del sistema.
■ Decisions //DECISIONES
    • Si el cliente no autoriza el acceso a su ubicación GPS, el mapa centrará su vista predeterminada en la capital o ciudad principal configurada en la plataforma.

CLIENTE BUSQUEDA EN MAPA
Steps
1. El Cliente ingresa a la sección de exploración y selecciona la opción "Vista en Mapa".
2. El sistema interactúa con el componente de mapas y solicita los permisos de ubicación del dispositivo o la ubicación guardada en el perfil del usuario.
3. El sistema evalúa el permiso de ubicación otorgado por el usuario:
    3.1. if el cliente deniega el acceso a la geolocalización o el dispositivo no cuenta con GPS activo: El sistema muestra un mensaje informativo "Geolocalización desactivada. Mostrando el mapa centrado en la ciudad predeterminada" y centra la vista en las coordenadas por defecto (ej. Centro de la ciudad).
    3.2. else if (Permiso concedido):El sistema obtiene las coordenadas actuales del usuario ($Lat, Long$) y centra la vista del mapa en su ubicación actual.
         end if
4. El sistema consulta en la base de datos los establecimientos registrados dentro de la cobertura del mapa visible.
5. El sistema evalúa el estado operativo de los locales encontrados:
    5.1. if un establecimiento se encuentra en estado Inactivo, Suspendido o Cancelado: El sistema omite la sede y no dibuja su marcador en la interfaz.
    5.2. else if (Establecimientos en estado Activo): El sistema renderiza los pines/puntos de interés en el mapa para cada sede.
         end if
6. El cliente hace clic sobre el pin de un establecimiento específico.
7. El sistema despliega la tarjeta resumen desplegable mostrando: Nombre comercial, Foto principal, Calificación promedio (RF18), Distancia aproximada y el botón "Ver Barbería" para ir a la información detallada o consultar disponibilidad
