Description

 

El sistema despliega la agenda operativa consolidada del establecimiento o de un profesional en específico.

El usuario puede filtrar la vista por rango de fechas (día, semana, mes), por sede o por barbero/especialista, obteniendo el detalle de las citas agendadas, canceladas, completadas o pendientes de atención.

PERSONAL/PROFESIONAL
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al panel de administración y navega al módulo "Agenda / Calendario de Citas".
    • Aplica filtros de búsqueda opcionales (fecha específica, sede o especialista asignado).
    • El sistema carga la cuadrícula o lista interactiva con todas las reservas correspondientes al criterio seleccionado.
    • Selecciona una cita para visualizar la ficha técnica detallada (datos del cliente, servicio solicitado, valor y estado actual).
■ Business Logic //LOGICA DE NEGOCIO
    • La agenda se actualiza automáticamente ante eventos de creación, modificación o cancelación de citas.
    • Los profesionales con rol operativo solo tendrán acceso a la consulta de su propia agenda, mientras que el Dueño tiene acceso a la agenda global de la empresa y de sus sedes.
    • Se asigna una codificación de colores por estado de cita (ej. Confirmada, En Proceso, Completada, Cancelada) para facilitar la lectura rápida del cronograma.
■ Decisions //DECISIONES
    • Si la fecha seleccionada no registra reservas agendadas, el sistema despliega una vista limpia indicando la disponibilidad total de la jornada.

personal/profesional
Steps
1. El Personal / Barbero ingresa a su panel operativo y selecciona la opción "Mi Agenda".
2. Selecciona la vista deseada (Diaria, Semanal o Filtro por fecha específica).
3. El sistema consulta la base de datos y recupera las citas vinculadas a su ID de profesional para la sede actual.
4. El sistema evalúa el estado y la existencia de compromisos en el rango consultado:
    4.1. if el profesional no tiene citas ni bloqueos programados para la fecha seleccionada: El sistema despliega la vista de la agenda limpia con el mensaje "No tienes servicios agendados para este día".
    4.2. else if El sistema lista de forma cronológica los turnos asignados mostrando: Nombre del cliente, Teléfono de contacto, Servicio a realizar, Duración, Estado de la cita (Confirmada, En Curso, Finalizada, Cancelada) y la indicación si requiere cobro en caja.
         end if
5. El barbero selecciona una cita específica para ver los detalles del servicio o cambiar su estado

Establecimiento (dueño)
Steps
1. El Dueño de Establecimiento accede al panel de administración y navega a "Agendas del Local".
2. Selecciona la sede y aplica filtros por fecha, por un profesional específico o la vista general consolidada de la sede.
3. El sistema recupera el consolidado de agendas de la base de datos.
4. El sistema evalúa la configuración y la respuesta del filtro:
    4.1. if el filtro seleccionado corresponde a un barbero inactivo o retirado de la sede: El sistema notifica "El colaborador seleccionado no forma parte de la nómina activa de esta sede".
    4.2. else if El sistema despliega la parrilla de agendamiento global en tiempo real, permitiendo visualizar los espacios libres, las citas confirmadas de cada sillón de trabajo, el avance de la jornada y los accesos rápidos para mover o cancelar turnos administrativos.
         end if
