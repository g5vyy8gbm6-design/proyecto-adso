El sistema despliega el catálogo de planes de suscripción vigentes parametrizados por el Superadministrador.

El usuario puede revisar la tabla comparativa de tarifas, periodos de facturación (mensual, trimestral, anual) y características incluidas en cada nivel de membresía para gestionar la afiliación de su local.

PLANES DE SUSCRIPCION
■ Workflow //FLUJO DE NEGOCIO
    • Ingresa al panel de administración del negocio y selecciona la sección "Suscripciones / Planes".
    • El sistema consulta la base de datos y carga el catálogo de planes activos.
    • Revisa los detalles de cada plan (costo, capacidad de agenda, número de empleados permitidos y funciones avanzadas).
    • Visualiza su plan actual marcado como "Activo" .
    • Opcionalmente, selecciona un nuevo plan para proceder al registro de pago o cambio de plan.
■ Business Logic //LOGICA DE NEGOCIO
    • Solo se muestran los planes de suscripción marcados con estado "Habilitado" en la plataforma global.
    • El sistema resalta el plan al que actualmente está suscrito el establecimiento junto con la fecha de vencimiento próxima.
    • Los precios presentados reflejan la moneda local ajustada por los parámetros del sistema.
■ Decisions //DECISIONES
    • Si el establecimiento opera bajo un periodo de prueba (free trial), el sistema desplegará un indicador con los días restantes antes de requerir la contratación de un plan pago.

FLUJO DE PASOS DE PLAN DE SUSCRIPCION
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a la sección "Mi Suscripción" => "Ver Planes Disponibles" (o durante el proceso de registro inicial del negocio).
2. El sistema consulta la base de datos y recupera el catálogo de planes comerciales activos configurados por la plataforma (ej. Plan Básico, Plan Profesional, Plan Enterprise).
3. El sistema evalúa el estado del catálogo y la suscripción actual del negocio:
    3.1. if la plataforma no cuenta con planes comerciales activos en el catálogo O se encuentra en mantenimiento de tarifas:
        3.1.1. El sistema despliega el aviso "El catálogo de planes se encuentra en actualización. Por favor, intente más tarde o contacte a soporte".
    3.2. else if
        3.2.1. El sistema proyecta la tabla comparativa de planes mostrando para cada opción: Nombre del plan, Tarifa (mensual/anual), Límite de barberos/colaboradores integrados, Límite de sedes, Comisión por transacción (si aplica), Acceso a reportes avanzados y funcionalidades incluidas.
        3.2.2. El sistema destaca de forma explícita el "Plan Actual" que posee la sede.
         end if
4. El propietario selecciona un nuevo plan y presiona el botón "Seleccionar Plan / Cambiar Plan".
5. El sistema evalúa la acción seleccionada:
    5.1. if el propietario elige el mismo plan que tiene activo actualmente:
        5.1.1. El sistema notifica "Ya cuentas con este plan activo en tu establecimiento"
    5.2. else if
        5.2.1. El sistema redirige al propietario al módulo de contratación y gestión de pagos de suscripción (Pasarela de Pagos).
         end if
6.
7.
