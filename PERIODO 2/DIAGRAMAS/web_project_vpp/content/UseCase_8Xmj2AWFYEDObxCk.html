Use Case - CAMBIAR ESTADO ESTABLECIMIENTO (ACTIVAR/INACTIVAR) link

Properties
Name Value
Description

 

El sistema permite modificar el estado operativo de un establecimiento registrado dentro de la plataforma (ej. pasar de Activo a Inactivo / Suspendido y viceversa).

Al cambiar el estado a "Inactivo", el local se oculta automáticamente del catálogo público, bloqueando la recepción de nuevas reservas, sin eliminar su historial contable o de clientes en la base de datos.

ACTIVAR Y DESACTIVAR POR SUPERADMIN
■ Workflow //FLUJO DE TRABAJO
    • Accede al panel general de administración y navega a "Consulta General de Establecimientos"
    • Selecciona el establecimiento sobre el cual desea actuar.
    • Presiona el botón de acción "Cambiar Estado" (Activar / Inactivar).
    • Selecciona el motivo del cambio de estado (ej. "Mora en Pago", "Incumplimiento de Términos", "Solicitud del Cliente").
    • Confirma la operación.
    • El sistema actualiza el registro, oculta/muestra el perfil en el explorador de clientes y notifica al dueño del local.
■ Business Logic //LOGICA DE NEGOCIO
    • La inactivación de un local no borra las citas previamente confirmadas, pero deshabilita de inmediato la opción de agendamiento para nuevos clientes.
    • Los establecimientos en estado "Inactivo" no aparecerán en los resultados de búsqueda , mapas ni listas por geolocalización.
    • El cambio de estado queda auditado en el sistema registrando la fecha, hora, usuario autorizador y justificación.
■ Decisions //DECISIONES
    • Si la inactivación es por mora, el sistema revertirá el estado a "Activo" automáticamente tan pronto como se apruebe el registro de pago pendiente.

(SUSPENSIÓN O REACTIVACIÓN ADMINISTRATIVA)
Steps
1. El Superadministrador ingresa a la consola central y navega a "Gestión de Establecimientos" => "Consulta General"
2. Selecciona un establecimiento específico y presiona el botón "Cambiar Estado (Activar / Inactivar / Suspender)".
3. El sistema despliega las opciones de estado disponbles (Activo, Inactivo, Suspendido) y exige ingresar la razón o justificación del cambio administrativo.
4. El Superadministrador confirma la acción.
5. El sistema evalúa el nuevo estado seleccionado:
    5.1. if el estado seleccionado es Inactivo o Suspendido:
        5.1.1. El sistema deshabilita inmediatamente la visibilidad de la sede en los motores de búsqueda, mapas y explorador del cliente (RF17, RF20, RF21, RF22).
        5.1.2. El sistema evalúa las citas futuras en estado Confirmada pertenecientes al establecimiento:
            5.1.2.1. if la sede tiene citas confirmadas pendientes por atender:
                5.1.2.1.1. El sistema cancela de oficio todas las reservas futuras bajo el motivo "Cancelada por suspensión del establecimiento", libera los compromisos de los clientes y procesa la reversión de sus cobros/creditos según corresponda.
            5.1.2.2. else if El sistema inactiva la agenda global de la sede directamente.
                5.1.2.2.1. El sistema bloquea el acceso de los barberos (RF13) y del Dueño de Establecimiento a sus paneles de operación hasta nuevo aviso.
                5.1.2.2.2. El sistema despacha la notificación de suspensión al correo del propietario explicando los motivos
            5.1.2.3. else if (Estado seleccionado es Activo): El sistema evalúa si el establecimiento cuenta con una suscripción vigente
                5.1.2.3.1. if la suscripción del negocio está vencida o rechazada: la suscripción del negocio está vencida o rechazada:
                    5.1.2.3.1.1. El sistema rechaza la activación y notifica "No se puede activar el establecimiento sin un plan de suscripción al día".
                5.1.2.3.2. else if
                    5.1.2.3.2.1. El sistema cambia el estado del local a Activo, restablece la publicación del perfil público (RF22) y envía la confirmación de reactivación al propietario
                           end if
                     end if
         end if

(SOLICITUD DE INACTIVACIÓN VOLUNTARIA DE SEDE)
Steps
1. El Dueño de Establecimiento ingresa al panel de configuración de la sede y selecciona la opción "Desactivar Mi Establecimiento Temporálmente".
2. El sistema verifica los compromisos vigentes del local:
    2.1. if la sede cuenta con citas programadas para los próximos días:
        2.1.1. El sistema bloquea la desactivación y muestra la alerta "No puedes inactivar la sede mientras existan citas pendientes por atender. Cancele o atienda las citas activas previamente".
    2.2. else if
        2.2.1. El sistema cambia el estado de la sede a Inactivo Voluntario, retira el negocio de las búsquedas de los clientes y envía la confirmación de inactivación voluntaria
         end if
