Use Case - RECUPERAR CONTRASEÑA link

Properties
Name Value
Description

El sistema permite a un usuario registrado solicitar el restablecimiento de su clave de acceso ingresando el correo electrónico asociado a su cuenta      . 

 

Tras verificar la existencia del correo en la base de datos, el sistema genera y envía un enlace o token de recuperación seguro con un tiempo de caducidad limitado      . El usuario accede al enlace recibido, ingresa una nueva contraseña cumpliendo con las políticas de seguridad y confirma el cambio, quedando habilitado inmediatamente para iniciar sesión con la nueva credencial      .

SUPERADMINISTRADOR
■ Workflow // FLUJO DE TRABAJO
    • Accede al formulario de solicitud de recuperación de contraseña desde la interfaz de login administrativo.
    • Ingresa su correo electrónico corporativo registrado como Superadministrador.
    • Recibe un correo seguro con un token/enlace de acceso temporal de un solo uso para restablecer su credencial.
    • Define su nueva contraseña cumpliendo con los estándares de seguridad administrativa e inicia sesión.
■ Business Logic // LOGICA DE NEGOCIO
    • Los enlaces de recuperación generados para este rol poseen un tiempo de caducidad más corto por estrictas políticas de seguridad.
    • La solicitud invalida automáticamente cualquier token de recuperación emitido previamente para esta cuenta.
    • Se debe registrar un evento de auditoría en los logs (registros) del sistema tras cada intento de recuperación de cuenta administrativa.
■ Decisions // DECISIONES
    • Por seguridad, si el correo ingresado no coincide con una cuenta activa de Superadministrador, la interfaz mostrará un mensaje genérico sin confirmar la existencia del correo.

ESTABLECIMIENTO (DUEÑO)
■ Workflow // FLUJO DE TRABAJO
    • Selecciona la opción "¿Olvidaste tu contraseña?" en la pantalla de inicio de sesión de la plataforma.
    • Ingresa el correo electrónico asociado a su cuenta de propietario del negocio
    • Abre el mensaje recibido en su bandeja de entrada y hace clic en el enlace de restablecimiento.
    • Asigna una nueva clave de acceso, confirma los cambios y es redirigido al login para ingresar a la gestión de su local.
■ Business Logic // LOGICA DE NEGOCIO
    • El enlace de recuperación es de un solo uso y expirará tras un tiempo determinado (ej. 5 minutos).
    • La nueva contraseña debe ser encriptada en la base de datos inmediatamente tras la confirmación.
    • El estado del establecimiento o de la suscripción no afecta la capacidad del dueño de restablecer su clave de acceso.
■ Decisions // DECISIONES
    • Se decide enviar un correo de notificación confirmando que la contraseña ha sido actualizada exitosamente como medida preventiva de seguridad.

PERSONAL/PROFESIONAL
■ Workflow // FLUJO DE TRABAJO
    • Solicita el restablecimiento de su clave desde la pantalla de login ingresando su correo registrado.
    • Recibe el enlace de verificación en su correo electrónico.
    • Ingresa al enlace, establece su nueva contraseña personal y guarda los cambios.
    • Inicia sesión nuevamente para acceder a su agenda operativa de trabajo.
■ Business Logic // LOGICA DE NEGOCIO
    • El profesional puede restablecer su contraseña de manera autónoma sin necesidad de depender del Dueño del local.
    • La cuenta debe estar activa y vinculada a un establecimiento para que el token de recuperación sea procesado correctamente.
■ Decisions // DECISIONES
    • En caso de que el Dueño haya inactivado al profesional, el proceso de recuperación permitirá cambiar la clave pero denegará el acceso al sistema hasta que la cuenta sea reactivada.

CLIENTE
■ Workflow // FLUJO DE TRABAJO
    • Hace clic en "¿Olvidaste tu contraseña?" dentro de la vista de login o al intentar completar una reserva.
    • Digita su correo electrónico registrado y envía la solicitud.
    • Revisa su correo, abre el enlace recibido e ingresa una nueva contraseña.
    • El sistema guarda los datos actualizados y le permite iniciar sesión para continuar navegando o reservando sus citas.
■ Business Logic // LOGICA DE NEGOCIO
    • El token de recuperación pierde validez inmediatamente después de ser utilizado.
    • El restablecimiento de contraseña no altera el historial de reservas, puntos ni el estado de sanciones previas del cliente
■ Decisions // DECISIONES
    • Se establece un flujo rápido que permite al cliente iniciar sesión automáticamente o redirigirse a la reserva activa tras actualizar la contraseña.

SUPERADMINISTRADOR
Steps
1. El Superadministrador accede al portal administrativo e inicia la recuperación de credenciales maestras.
2. Ingresa el correo electrónico asignado a la cuenta de Superadministrador.
3. El sistema valida la cuenta y genera un token de un solo uso asociado a un código de autenticación de dos factores (2FA/MFA).
4. El Superadministrador abre el enlace e ingresa la nueva clave junto con el código dinámico de su aplicación de autenticación.
5. El sistema evalúa el código de seguridad dinámico:
    5.1. if el código dinámico de autenticación es Incorrecto: El sistema deniega el cambio de clave y registra el evento como un intento fallido de seguridad en la bitácora global.
    5.2. else if El sistema actualiza la clave maestra en la base de datos, revoca las sesiones activas abiertas en otros dispositivos y solicita iniciar sesión con las nuevas credenciales.
         end if

ESTABLECIMIENTO (DUEÑO)
Steps
1. El usuario accede a la pantalla de inicio de sesión y selecciona la opción "¿Olvidaste tu contraseña?".
2. El usuario ingresa su correo electrónico registrado y presiona "Enviar Enlace de Recuperación".
3. El sistema busca la dirección de correo en la base de datos.
4. El sistema evalúa la existencia de la cuenta:
    4.1. if el correo electrónico NO se encuentra registrado en el sistema: El sistema despliega un mensaje genérico por seguridad ("Si el correo ingresado está asociado a una cuenta, recibirás un enlace de recuperación") para evitar la extracción indebida de correos.
    4.2. else if (El correo sí existe en la base de datos): El sistema genera un token de seguridad único de un solo uso con vigencia temporal limitada (ej. 15 minutos).
        4.2.1. El sistema despacha un correo electrónico al usuario con la URL de restablecimiento que contiene el token encriptado.
         end if
5. El usuario abre su bandeja de entrada, hace clic en el enlace recibido e ingresa su nueva contraseña en el formulario.
6. El sistema evalúa el token de la URL:
    6.1. if el token ha Expirado o ya fue Utilizado previamente: El sistema bloquea el formulario y muestra la alerta "El enlace de recuperación ha caducado. Por favor, solicita uno nuevo".
    6.2. else if (Token Válido): El sistema evalúa la nueva contraseña ingresada:
        6.2.1. if la nueva contraseña NO cumple con los parámetros de seguridad (mínimo 8 caracteres, mayúscula, número y carácter especial) O no coincide con la confirmación: El sistema rechaza la solicitud y resalta las reglas de seguridad no cumplidas en pantalla.
        6.2.2. else if El sistema encripta la nueva contraseña (mediante algoritmo Hash), actualiza el registro en la base de datos, inactiva el token consumido y redirige al usuario a la pantalla de inicio de sesión con una notificación de éxito.
               end if
         end if

Preconditions El usuario debe tener una cuenta registrada previamente en la plataforma Fresh Style con un correo electrónico válido e inaccesible mediante su clave actual, y contar con conexión a internet para recibir el mensaje de verificación.
Post-conditions La contraseña del usuario queda actualizada y cifrada de forma segura en la base de datos, invalidadas las claves o tokens anteriores, y el usuario queda habilitado para iniciar sesión inmediatamente con sus nuevas credenciales.
