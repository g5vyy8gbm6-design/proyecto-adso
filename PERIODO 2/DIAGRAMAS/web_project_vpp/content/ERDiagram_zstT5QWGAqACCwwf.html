Name Description
 Reserva_Servicio_Empleado : Entity 		Tabla asociativa que detalla los servicios específicos y el empleado asignado para cada reserva, indicando la hora y el valor particular .
 Servicio_Empleado : Entity 		Tabla intermedia que relaciona los servicios ofertados con los empleados capacitados para prestarlos.
 Empleado : Entity 		Almacena la información del personal de trabajo, su sede asignada y sus datos operativos.
 Reserva : Entity 		Registra la solicitud de citas o reservas programadas por los usuarios.
 Cliente : Entity 		Almacena la información de perfil asociada a los usuarios que actúan como clientes dentro del sistema.
 Establecimiento : Entity 		Contiene la información de las sedes, lugares o locales registrados donde se prestan los servicios.
 Tipo_documento : Entity 		Almacena el catálogo de tipos de documentos de identidad admitidos por el sistema
 Servicio : Entity 		Catálogo de los servicios ofertados por los establecimientos en el sistema.
