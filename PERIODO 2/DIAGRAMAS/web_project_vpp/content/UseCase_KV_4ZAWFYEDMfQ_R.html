Use Case - CAMBIAR PLAN DE SUSCRIPCION link

Properties
Name Value
Description

 

El sistema permite al dueño del establecimiento solicitar y procesar la modificación de su plan de suscripción actual dentro de la plataforma.

El propietario selecciona la nueva modalidad (ej. de Plan Básico a Premium), el sistema recalcula los cobros o prorrateos correspondientes, procesa la transacción financiera y actualiza de inmediato los límites y permisos de la cuenta del local.

DUEÑO ESTABLECIMIENTO
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al panel de administración y navega a "Configuración del Negocio" => "Plan y Suscripción".
    • El sistema despliega la información del plan actual y la tabla comparativa de planes disponibles
    • Selecciona el nuevo plan deseado y presiona "Cambiar Plan".
    • Revisa el desglose de cobro (monto prorrateado o diferencia a pagar) y selecciona el método de pago.
    • El sistema procesa el pago a través de la pasarela transaccional.
    • Confirmado el pago, el sistema actualiza la membresía y habilita de inmediato los nuevos límites de la plataforma.
■ Business Logic //LOGICA DE NEGOCIO
    • La habilitación de nuevos beneficios (ej. más cupos de empleados o sedes) es inmediata tras confirmarse la transacción.
    • Si el propietario decide pasar a un plan inferior, el sistema validará que los recursos activos del local (cantidad de empleados o sedes) no superen el límite del nuevo plan objetivo.
    • Si los recursos actuales superan el límite del plan inferior, el sistema exigirá inhabilitar o inactivar el exceso de empleados/sedes antes de autorizar el cambio.
■ Decisions //DECISIONES
    • Si los recursos actuales superan el límite del plan inferior, el sistema exigirá inhabilitar o inactivar el exceso de empleados/sedes (RF32) antes de autorizar el cambio.

(UPGRADE O DOWNGRADE DE PLAN DE SUSCRIPCIÓN)
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a "Mi Suscripción" => "Cambiar de Plan".
2. El sistema consulta la base de datos de planes disponibles y la suscripción activa del establecimiento.
3. El propietario selecciona un nuevo plan (un plan superior - Upgrade o un plan inferior - Downgrade) y confirma la solicitud.
4. El sistema evalúa el tipo de cambio seleccionado:
    4.1. if la solicitud corresponde a un Downgrade (cambio a un plan con menores prestaciones):
        4.1.1. El sistema evalúa la nómina de colaboradores y sedes activas del negocio contra los límites del nuevo plan:
            4.1.1.1. if el establecimiento supera el número máximo de barberos/empleados o sedes permitidos por el plan inferior seleccionado:
                4.1.1.1.1. El sistema frena la solicitud y notifica "No puedes cambiar a un plan inferior porque superas los límites permitidos (empleados/sedes). Debes inhabilitar colaboradores antes de realizar el downgrade".
            4.1.1.2. else if El sistema programa el cambio de plan para que surta efecto al finalizar el ciclo de facturación actual sin cobros adicionales inmediatos.
                     end if
    4.2. else if (Solicitud corresponde a un Upgrade - plan superior):
        4.2.1. El sistema calcula el valor prorrateado por la diferencia de tarifa entre el plan actual y el nuevo plan.
        4.2.2. El sistema redirige al propietario al registro e ingreso del pago correspondiente Registro de Pagos Suscripción).
        4.2.3. Una vez validado o procesado el pago:
            4.2.3.1. El sistema actualiza inmediatamente los límites y beneficios del nuevo plan para la sede y notifica la confirmación del cambio por correo
         end if

(AJUSTE ADMINISTRATIVO O MIGRACIÓN FORZOSA DE PLAN)
Steps
1. El Superadministrador accede a la consola global de administración de establecimientos.
2. Selecciona un negocio específico y presiona la opción "Modificar Plan de Suscripción".
3. Selecciona el nuevo plan de destino y registra la justificación administrativa.
4. El sistema evalúa las reglas operativas del negocio:
    4.1. if el ajuste administrativo implica asignar un plan de menor capacidad y la sede excede los recursos permitidos:
        4.1.1. El sistema muestra la advertencia de exceso de capacidad pero permite al Superadministrador forzar la migración asignando una excepción o congelando la creación de nuevos empleados.
    4.2. else if
        4.2.1. El sistema actualiza de inmediato el plan asociado al establecimiento, recalcula la fecha de vencimiento y notifica al propietario sobre la actualización del plan
         end if
