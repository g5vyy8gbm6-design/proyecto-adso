Use Case - REGISTRAR USUARIO link

Properties
Name Value
Description

El sistema permite a un usuario no registrado crear una cuenta en la plataforma Fresh Style ingresando sus datos personales obligatorios: nombres completos, correo electrónico, número telefónico, fecha de nacimiento y contraseña.

 

el sistema realiza validaciones automáticas para verificar que la información cumpla con los formatos requeridos y que el correo electrónico ingresado no se encuentre previamente registrado en la base de datos      . Una vez validada y almacenada la información, el usuario queda registrado correctamente y habilitado para iniciar sesión      .

SUPERADMINISTRADOR
■ Workflow // flujo de trabajo
    • El Superadministrador no se registra mediante el formulario público de la plataforma web.
    • El usuario creador/superadministrador es inicializado directamente en la base de datos mediante un script de despliegue (seeding/migration) o creado por un administrador de sistemas de nivel superior.
    • Accede al panel de autenticación privado utilizando sus credenciales maestras y confirma la configuración inicial de su perfil.
    • Una vez autenticado, accede al panel de control global desde donde puede administrar otros roles y superadministradores adicionales si fuese necesario.
■ Business // logica de negocio
    • La cuenta de Superadministrador posee el nivel más alto de privilegios (Rol: SuperAdmin) dentro del sistema Fresh Style.
    • Para evitar vulnerabilidades, el sistema impide la creación pública de cuentas con rol de Superadministrador.
    • La credencial principal (correo electrónico) debe estar protegida y asociada a medidas estrictas de autenticación.
    • No requiere asociación a ningún establecimiento comercial ni suscripción de pago.
■ Decisions// Desiciones
    • Se decide que la cuenta inicial de Superadministrador se cree durante la fase de instalación/despliegue del backend mediante un script seguro.
    • Se restringe el acceso al panel administrativo maestro únicamente a direcciones IP/rutas específicas o protegidas por middleware de seguridad.
    • Si se requiere otorgar permisos de Superadministrador a un nuevo usuario, esto solo podrá ser realizado desde dentro del panel del Superadministrador existente.
■

ESTABLECIMIENTO (DUEÑO)
■ Workflow // flujo de trabajo
    • Accede al formulario de registro público o al módulo comercial de registro de negocios.
    • Completa sus datos personales (nombres completos, correo electrónico, teléfono, fecha de nacimiento y contraseña).
    • Selecciona la opción de registro como propietario o administrador de establecimiento.
    • Al confirmar la creación de su cuenta de usuario, el sistema lo redirecciona al asistente de configuración donde ingresa la información inicial de su local (nombre comercial, nit, dirección, tipo de servicio y plan de suscripción).
■ Business // logica de negocio
    • La cuenta creada adquiere el rol de Dueño de Establecimiento (Admin de Local).
    • El correo del propietario debe ser único y verificado, ya que será la cuenta receptora de las notificaciones de pagos, renovaciones y alertas administrativas.
    • La activación operacional de su local para recibir reservas queda sujeta a la vinculación y validación de un plan de suscripción válido (Básico o Premium).
■ Decisions// Desiciones
    • Se decide unificar el alta del Dueño en un proceso en dos etapas: primero creación del perfil de usuario y posteriormente vinculación/alta del establecimiento.
    • Se exige que el Dueño acepte los términos y condiciones específicos para comercios afiliados durante el proceso de registro.
■

PERSONAL/PROFESIONAL
■ Workflow // flujo de trabajo
    • El Personal/Profesional no se registra de forma libre en la plataforma abierta.
    • El Dueño del Establecimiento diligencia el formulario interno de alta de empleados, ingresando los datos del profesional (nombre, correo, teléfono, especialidades y horarios)
    • El sistema genera la cuenta con el rol Personal/Profesional y envía una notificación automática o credenciales temporales al correo del empleado
    • El profesional ingresa por primera vez al sistema, valida su correo y actualiza su clave de acceso para activar su perfil.
■ Business // logica de negocio
    • La cuenta del profesional debe estar estrictamente vinculada a la cuenta de un establecimiento activo.
    • El número máximo de profesionales que se pueden registrar en un local depende de la capacidad del plan de suscripción contratado por el Dueño.
    • Si el establecimiento es inhabilitado o suspendido, las cuentas de sus profesionales quedan temporalmente bloqueadas para la gestión de citas.
■ Decisions// Desiciones
    • Se decide bloquear la opción de autoregistro público para profesionales con el fin de evitar que se vinculen a locales sin autorización del propietario.
    • El estado del usuario profesional (Activo/Inactivo) será controlado exclusivamente por el Dueño del local.
■

CLIENTE
■ Workflow // flujo de trabajo
    • Ingresa a la plataforma web o aplicación desde su dispositivo mediante el formulario público de registro.
    • Ingresa los datos solicitados: nombres completos, correo electrónico, teléfono, fecha de nacimiento y contraseña.
    • Acepta la política de tratamiento de datos personales y términos del servicio.
    • El sistema valida la información, guarda el registro en la base de datos y envía un correo electrónico de bienvenida/confirmación.
    • Queda autenticado e inicia sesión automáticamente o se redirige a la pantalla de login.
■ Business // logica de negocio
    • Asignación automática del rol Cliente con permisos orientados al módulo de búsqueda, geolocalización y reservas.
    • El sistema verifica que el correo electrónico no esté registrado previamente en la base de datos para evitar cuentas duplicadas.
    • El cliente inicia sin sanciones activas y con su contador mensual habilitado para el control de cancelaciones (máximo 5 por mes)
■ Decisions// Desiciones
    • Se establece un formulario de registro simple para acelerar la conversión y reducir el abandono de usuarios.
    • Se decide exigir la fecha de nacimiento para verificar la mayoría de edad y permitir personalización de ofertas de cumpleaños en el futuro

SUPERADMINISTRADOR
Steps
1. El Superadministrador ejecuta el proceso de siembra inicial o despliegue del sistema en el servidor.
2. El sistema evalúa si existen cuentas maestras previamente creadas:
    2.1. if el rol maestro ya existe en la base de datos: El sistema omite la creación duplicada y envía una alerta de inicialización previa.
    2.2. else if El sistema crea el usuario raíz con credenciales maestras y habilita la plataforma global.
         end if

ESTABLECIMIENTO (DUEÑO)
Steps
1. El Dueño de Establecimiento accede al formulario de registro institucional en la plataforma web.
2. Ingresa los datos personales, correo electrónico, NIT/Cédula y nombre del negocio.
3. El sistema evalúa la validez y duplicidad del correo/documento:
4. si el correo electrónico o NIT ya se encuentra registrado en el sistema:
5. if El sistema frena el proceso y despliega el mensaje "El usuario o establecimiento ya existe".
6. else if El sistema registra el nuevo negocio en estado Pendiente de Verificación, guarda la cuenta en la base de datos y envía el correo de activación.
   end if

PERSONAL/PROFESIONAL
Steps
1. El Personal / Barbero recibe un enlace de invitación enviado a su correo por el Dueño.
2. Accede al formulario de registro interno y completa sus datos personales y contraseña.
3. El sistema evalúa el token de la invitación:
4. if el token ha expirado o es inválido: El sistema deniega el registro e informa que la invitación ha caducado.
5. else if El sistema crea la cuenta de empleado, la vincula automáticamente a la sede correspondiente del negocio y habilita su perfil de trabajo.
   end if

CLIENTE
Steps
1. El Cliente accede a la aplicación web/móvil y presiona "Crear Cuenta".
2. Ingresa su nombre, teléfono, correo electrónico y contraseña.
3. El sistema evalúa la disponibilidad del correo y teléfono:
4. if los datos ya están vinculados a otro perfil: El sistema notifica la duplicidad y sugiere recuperar la contraseña.
5. else if El sistema genera la cuenta de cliente activa y le da la bienvenida para iniciar búsquedas y reservas.
   end if
