PANEL DE RESERVAS : System

Use Case - VALIDAR CONTROL DE CANCELACIONES MENSUALES link

Properties
Name Value
Description

 

El sistema lleva un contador dinámico del número de cancelaciones ejecutadas por cada cliente dentro del mes calendario vigente.

Si un cliente alcanza el límite máximo parametrizado por el negocio (ej. 3 cancelaciones al mes), el sistema restringe su capacidad para agendar nuevas citas de forma autónoma, exigiendo la intervención del personal o el dueño para levantar la sanción o solicitar un pago anticipado obligatorio.

CLIENTE
■ Workflow //FLUJO DE TRABAJO
    • Solicita la cancelación de una cita dentro de su panel "Mis Citas".
    • El sistema verifica la regla del (5 horas previas) y consulta su contador mensual de cancelaciones
    • Si el contador mensual no llega al limite maximo
    • El sistema procesa la cancelación y suma +1 al contador mensual del cliente.
    • Si el contador mensual llega al limite maximo
    • El sistema ejecuta la cancelación, pero actualiza el perfil del cliente a estado "Restringido por Cancelaciones", bloqueándole la opción de realizar nuevas reservas durante el resto del mes.
■ Business Logic //LOGICA DE NEGOCIO
    • El contador mensual de cancelaciones por cliente se reinicia automáticamente a cero, en cada dia 1 de cada mes a las 00:00h
    • Las citas canceladas por iniciativa del Personal o del Dueño no suman al contador de cancelaciones del cliente.
    • Un cliente en estado "Restringido por Cancelaciones" no podrá agendar citas en línea para ningún establecimiento de la red hasta que venza el periodo o sea desbloqueado.
■ Decisions //DECISIONES
    • Si el Dueño lo configura, un cliente que haya superado el tope mensual podrá seguir agendando únicamente si realiza el pago del 100% del valor del servicio por anticipado a través de la pasarela de pagos (no reembolsable en caso de nueva cancelación).

(VERIFICACIÓN Y CONTABILIZACIÓN DE LÍMITE DE CANCELACIONES)
Steps
1. El Cliente solicita la cancelación de una cita desde su panel de reservas ( Cancelación de Citas).
2. El sistema verifica el cumplimiento de la ventana de tiempo ( Regla Cancelación Anticipada).
3. El sistema consulta en la base de datos el historial de cancelaciones acumuladas por el cliente dentro del mes de calendario actual (del día 1 al último día del mes en curso).
4. El sistema incrementa el contador mensual del usuario
5. El sistema evalúa el número de cancelaciones acumuladas contra el límite máximo permitido por política de plataforma (ej. máximo 3 cancelaciones al mes):
    5.1. if el contador de cancelaciones del cliente en el mes es menor al límite máximo permitido
        5.1.1. El sistema registra la cancelación normalmente en el historial del cliente
        5.1.2. El sistema despliega un mensaje informativo de advertencia: "Cita cancelada con éxito. Has realizado [N] de 3 cancelaciones permitidas este mes".
        5.1.3. El sistema notifica la cancelación al cliente y al local
    5.2. else if
        5.2.1. El sistema registra la tercera cancelación y marca la cuenta del usuario en estado de alerta por reincidencia.
        5.2.2. El sistema gatilla en segundo plano el proceso de sanción por uso inadecuado de la plataforma
        5.2.3. El sistema despliega la notificación de advertencia grave: "Has alcanzado el límite máximo de cancelaciones mensuales (3/3). Tu cuenta ha sido sancionada temporalmente para realizar nuevas reservas".
         end if

(REINICIO MENSUAL DEL CONTADOR)
Steps
1. El Sistema ejecuta un proceso programado automático el primer día de cada mes a las 00:00 horas.
2. El sistema consulta la lista global de clientes activos y sancionados.
3. El sistema evalúa el estado del contador mensual de cada usuario:
    3.1. if el usuario superó o alcanzó el límite en el mes anterior Y su período de sanción ya ha expirado:
        3.1.1. El sistema reinicia el contador de cancelaciones mensuales a cero
    3.2. else if
        3.2.1. if la sanción temporal emitida en el aún tiene días pendientes por cumplir:
            3.2.1.1. El sistema mantiene el bloqueo activo para nuevas reservas hasta que se cumpla el tiempo reglamentario de penalización, aunque reinicie el contador del nuevo mes.
        3.2.2. else if
            3.2.2.1. El sistema simplemente reinicia el contador mensual a cero
               end if
         end if
