Description

El sistema permite a un usuario registrado como Dueño de Establecimiento solicitar el alta de su local comercial completando un formulario con los datos de la empresa

(nombre comercial, NIT/RUT, dirección física, teléfono de contacto, categoría, horarios de atención e imágenes del establecimiento).

 REGISTRAR ESTABLECIMIENTO : Use Case

ESTABLECIMIENTO (DUEÑO)
■ Workflow // FLUJO DE TRABAJO
    • Accede a la opción "Registrar Mi Establecimiento" dentro de su panel de usuario.
    • Diligencia la información general del negocio (nombre comercial, dirección, teléfono, NIT/identificación tributaria, categoría y horarios de atención).
    • Adjunta imágenes del local (logo y fotos publicitarias).
    • Envía el formulario para guardar los datos.
    • Visualiza el mensaje de confirmación y accede a la pantalla de configuración inicial de su local.
■ Business Logic // LOGICA DE NEGOCIO
    • Un usuario con rol Dueño de Establecimiento puede registrar uno o múltiples establecimientos según las reglas de su plan de suscripción.
    • El NIT/RUT o número de identificación tributaria debe ser único en la plataforma para evitar duplicidad de empresas.
    • Los campos de ubicación (dirección, ciudad, barrio) son obligatorios para permitir la geolocalización por parte de los clientes.
■ Decisions // DECISIONES
    • Se valida que las imágenes cargadas cumplan con los formatos permitidos (PNG, JPG) y un tamaño máximo de archivo.
    • Si el negocio requiere verificación por parte del Superadministrador, el establecimiento queda en estado "Pendiente de Aprobación" antes de ser visible en el catálogo público para clientes.

Scenario
Steps
1. El Dueño de Establecimiento accede al panel administrativo y selecciona la opción "Registrar Nuevo Establecimiento".
2. Completa el formulario institucional ingresando: NIT/RUT, Nombre Comercial, Dirección Físico-Geográfica, Teléfono de Contacto, Categoría (Barbería/Peluquería), Horarios de Atención y Fotos del local.
3. Presiona el botón "Guardar y Solicitar Registro".
4. El sistema evalúa la información y la existencia previa del local:
    4.1. if el NIT/RUT o Nombre Comercial en esa dirección ya se encuentra registrado en el sistema: El sistema frena la operación y notifica "El establecimiento con este NIT/Ubicación ya existe en la plataforma".
    4.2. else if El sistema evalúa la validez de las coordenadas de dirección/geolocalización:
        4.2.1. if la dirección no es válida en el mapa del sistema: El sistema solicita ajustar el pin o la dirección física.
        4.2.2. else if El sistema registra el establecimiento en estado "Pendiente de Aprobación" o "Inactivo", guarda los datos en la base de datos y genera una notificación al Superadministrador para su revisión.
               end if
         end if
