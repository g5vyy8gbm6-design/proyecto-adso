Properties
Name Value
Description

 

El sistema permite al propietario gestionar el catálogo de servicios de su establecimiento, brindando la capacidad de crear, consultar, modificar y cambiar el estado (activar/inactivar) de cada servicio ofertado.

 

Durante el registro o edición, el usuario parametriza el nombre del servicio, descripción, precio, tiempo estimado de duración, categoría y profesionales habilitados para realizarlo.

 REGISTRAR SERVICIOS : Use Case

ESTABLECIMIENTO (DUEÑO)
■ Workflow // FLUJO DE TRABAJO
    • Accede al módulo "Gestión de Servicios" desde el menú de administración de su local.
    • Visualiza el listado de servicios agrupados por categorías con sus precios y estados actuales.
    • Selecciona "Crear Servicio" para registrar una nueva opción, o hace clic en un servicio existente para editar sus parámetros.
    • Define o actualiza los campos requeridos (nombre, categoría, precio, duración en minutos, descripción e imagen representativa).
    • Habilita o inactiva el servicio según la disponibilidad operativa.
    • Guarda los cambios y el sistema actualiza el catálogo.
■ Business Logic // LOGICA DE NEGOCIO
    • El precio debe ser un valor numérico positivo mayor a cero y la duración debe definirse en intervalos de tiempo válidos
    • La inactivación de un servicio no cancela las reservas que fueron confirmadas previamente con dicho servicio.
    • Cada servicio debe estar vinculado al menos a una categoría para facilitar la búsqueda en el catálogo del cliente.
■ Decisions // DECISIONES
    • Si un servicio es modificado en precio o duración, los cambios solo aplican para las nuevas reservas; las citas agendadas previamente conservan las condiciones iniciales.
    •

ESTABLECIMIENTO (DUEÑO)
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a "Gestión del Negocio" => "Catálogo de Servicios".
2. Presiona el botón "Agregar Nuevo Servicio" e ingresa los datos: Nombre del servicio, Descripción, tiempo duracion de servicio en min, Precio base, Foto/Imagen ilustrativa y Categoría (Corte, Barba, Combo, etc.).
3. Asigna los profesionales de la sede autorizados para realizar dicho servicio.
4. Presiona el botón "Guardar Servicio".
5. El sistema evalúa la información y duplicidad de registros:
    5.1. if el nombre del servicio ya existe para la misma sede O la duración es igual a 0 minutos:El sistema frena el registro y notifica "El servicio ya existe o los datos de duración son inválidos".
    5.2. else if El sistema guarda el servicio en la base de datos en estado "Activo", lo vincula a los barberos seleccionados y actualiza la oferta comercial del local.
         end if
