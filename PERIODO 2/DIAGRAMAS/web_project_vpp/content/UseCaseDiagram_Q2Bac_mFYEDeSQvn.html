  BUSQUEDA Y EXPLORACION : System

Proporciona herramientas de descubrimiento activo y geolocalizado, permitiendo a los usuarios buscar establecimientos, consultar la disponibilidad de agendas en tiempo real, visualizar sedes en un mapa interactivo y filtrar resultados por ubicación cercana, servicios o criterios específicos. Su objetivo principal es facilitar el proceso de exploración previo a la toma de decisión y reserva de citas.

  PANEL ADMINISTRATIVO DE ESTABLECIMIENTO DUEÑO : System

Permite la gestión integral de la información comercial y operativa del negocio, incluyendo el registro y administración de sedes, parametrización del catálogo de servicios, control de personal/profesionales, gestión de horarios de atención y el monitoreo general de las reservas e ingresos del local.

  AUTENTICACION Y PERFILES : System

 

Este paquete agrupa los casos de uso fundamentales encargados de validar la identidad de los usuarios y gestionar su información dentro de la plataforma Fresh Style      . Constituye la capa base de seguridad y personalización del sistema, permitiendo:     

  • Control de acceso y seguridad: Garantiza que únicamente los usuarios autenticados puedan interactuar con las funcionalidades del sistema según su rol      .     

  • Gestión de identidad: Facilita el alta de nuevos usuarios (RF01)      , la validación de credenciales (RF02)      y el restablecimiento seguro de claves (RF03)      .     

  • Personalización y trazabilidad: Permite a los usuarios actualizar sus datos personales (RF04)      y consultar restricciones o sanciones asociadas a su cuenta (RF42)      , asegurando la integridad de los datos e historial del usuario      .

  INICIAR SESION : Use Case

El sistema permite a un usuario previamente registrado acceder a la plataforma web mediante el ingreso de sus credenciales de acceso: correo electrónico y contraseña.  

el sistema valida las credenciales contra la base de datos      . Si la información es correcta, genera una sesión activa y redirige al usuario al panel de control correspondiente a su rol      . En caso de credenciales incorrectas o cuenta inactiva/suspendida, el sistema bloquea el acceso y muestra un mensaje informativo      . 

  RECUPERAR CONTRASEÑA : Use Case

El sistema permite a un usuario registrado solicitar el restablecimiento de su clave de acceso ingresando el correo electrónico asociado a su cuenta      . 

 

Tras verificar la existencia del correo en la base de datos, el sistema genera y envía un enlace o token de recuperación seguro con un tiempo de caducidad limitado      . El usuario accede al enlace recibido, ingresa una nueva contraseña cumpliendo con las políticas de seguridad y confirma el cambio, quedando habilitado inmediatamente para iniciar sesión con la nueva credencial      .

  MODIFICAR PERFIL : Use Case

El sistema permite a cualquier usuario autenticado acceder a la configuración de su cuenta para consultar y actualizar sus datos personales (como nombre, teléfono, fecha de nacimiento o contraseña)      . 

 

El usuario modifica los campos deseados y envía el formulario; el sistema valida el formato de los datos ingresados y guarda los cambios en la base de datos      . En caso de requerir la modificación de credenciales sensibles, se aplican confirmaciones de seguridad adicionales      .

  REGISTRAR ESTABLECIMIENTO : Use Case

El sistema permite a un usuario registrado como Dueño de Establecimiento solicitar el alta de su local comercial completando un formulario con los datos de la empresa

(nombre comercial, NIT/RUT, dirección física, teléfono de contacto, categoría, horarios de atención e imágenes del establecimiento).

  REGISTRAR PERSONAL : Use Case

 

El sistema permite al dueño del establecimiento dar de alta un nuevo trabajador o colaborador en la plataforma.

Captura la información personal y laboral del empleado (nombre completo, documento de identidad, teléfono, correo electrónico, foto de perfil, cargo, especialidades y horario asignado) y crea sus credenciales de acceso con rol de Personal.

  CONSULTAR MIS ESTABLECIMIENTOS : Use Case

El sistema permite al propietario dar de alta, modificar y administrar las diferentes sedes físicas pertenecientes a su marca o empresa.

El usuario configura la dirección específica, teléfono directo, horarios particulares y estado operativo de cada sucursal, permitiendo que los clientes seleccionen la sede más cercana al momento de reservar.

  REGISTRAR SERVICIOS : Use Case

 

El sistema permite al propietario gestionar el catálogo de servicios de su establecimiento, brindando la capacidad de crear, consultar, modificar y cambiar el estado (activar/inactivar) de cada servicio ofertado.

 

Durante el registro o edición, el usuario parametriza el nombre del servicio, descripción, precio, tiempo estimado de duración, categoría y profesionales habilitados para realizarlo.

  CONSULTAR DISPONIBILIDAD DE ESTABLECIMIENTO : Use Case

 

El sistema permite al cliente explorar y verificar en tiempo real las franjas de tiempo libres para la atención de un servicio o profesional específico.

Tras seleccionar la sede, el servicio deseado y la fecha preferida, la plataforma procesa la matriz de horarios operativos y las citas previamente confirmadas para desplegar la agenda interactiva disponible.

  AGENDAR RESERVA : Use Case

 

El sistema permite al cliente seleccionar un servicio, fecha, horario y profesional disponible para registrar una cita formal en la plataforma.

El proceso valida la ausencia de sanciones o bloqueos previos en la cuenta del cliente, reserva la franja horaria en la agenda del establecimiento y envía notificaciones automáticas de confirmación a ambas partes.

  MODIFICAR RESERVA ACTIVAS : Use Case

 

El sistema permite al cliente reprogramar la fecha, hora o el profesional asignado a una cita agendada previamente.

 

La plataforma valida que la modificación se realice dentro de los plazos temporales permitidos por las políticas del negocio, libera el espacio anterior en la agenda y reagenda el servicio en la nueva franja horaria seleccionada.

  CANCELAR RESERVA : Use Case

 

El sistema permite al cliente cancelar una cita confirmada previa a su ejecución.

La plataforma valida que la solicitud cumpla con los tiempos de anticipación establecidos (ej. mínimo 5 horas de antelación), registra el motivo de la cancelación, libera el cupo en la agenda del establecimiento y envía una notificación automática a ambas partes.        

  CONSULTAR AGENDA DIARIA : Use Case

 

El sistema despliega la agenda operativa consolidada del establecimiento o de un profesional en específico.

El usuario puede filtrar la vista por rango de fechas (día, semana, mes), por sede o por barbero/especialista, obteniendo el detalle de las citas agendadas, canceladas, completadas o pendientes de atención.

  ENVIAR NOTIFICACIONES AUTOMATICAS : Use Case

El sistema genera y distribuye alertas automáticas (vía correo electrónico, SMS o notificaciones push) desencadenadas por acciones operativas en la plataforma.

  CONSULTAR HISTORIAL DE RESERVAS : Use Case

 

El sistema despliega el registro histórico de todas las citas agendadas por el cliente dentro de la plataforma.

La información se organiza de forma cronológica y permite filtrar entre citas activas/próximas, completadas, canceladas o no asistidas, mostrando detalles de fecha, hora, local, profesional, costo y comprobante digital.

  BUSCAR ESTABLECIMIENTOS : Use Case

 

El sistema permite a los usuarios buscar y localizar establecimientos registrados ingresando términos clave como nombre del local, barrio, ciudad o especialidad del servicio.

La plataforma procesa los parámetros de búsqueda y despliega un listado de resultados coincidentes con información básica (nombre, foto de portada, ubicación y calificación promedio) para iniciar la exploración del perfil.

  GENERAR REPORTES BASICOS : Use Case

 

El sistema permite al propietario generar y visualizar reportes analíticos básicos sobre la actividad de sus sedes y personal.

El usuario selecciona un rango de fechas y el tipo de reporte deseado (ventas, citas completadas, cancelaciones o ingresos por barbero), y el sistema procesa los datos para presentarlos en gráficos e indicadores consolidados exportables.

  VISUALIZAR EN MAPA : Use Case

 

El sistema despliega una interfaz de mapa interactivo donde se ubican los marcadores o pins de los establecimientos registrados y activos en la plataforma.

El cliente puede interactuar con el mapa (hacer zoom, desplazarse o hacer clic en un marcador) para visualizar una vista previa rápida del local (nombre, foto, dirección y calificación) y acceder directamente a su perfil de reservas.

  BUSCAR ESTABLECIMIENTOS CERCANOS : Use Case

 

El sistema utiliza las coordenadas geográficas en tiempo real del dispositivo del cliente para calcular y ordenar los establecimientos más cercanos a su ubicación actual.

La plataforma calcula la distancia lineal entre la posición del usuario y las sedes registradas, desplegando un listado priorizando el margen de proximidad en kilómetros o metros.

  VER INFORMACION DE UBICACION : Use Case

 

El sistema despliega la ficha detallada de la ubicación física de un establecimiento seleccionado.

Muestra la dirección exacta, el municipio, la ciudad, las indicaciones o puntos de referencia, e integra un acceso directo que redirige a aplicaciones externas de navegación para trazar la ruta punto a punto

  CONSULTAR PLANES DE SUSCRIPCION : Use Case

 

El sistema despliega el catálogo de planes de suscripción vigentes parametrizados por el Superadministrador.

El usuario puede revisar la tabla comparativa de tarifas, periodos de facturación (mensual, trimestral, anual) y características incluidas en cada nivel de membresía para gestionar la afiliación de su local.

  REGISTROS DE PAGOS DE SUSCRIPCION : Use Case

El sistema permite al dueño del establecimiento registrar y procesar el pago correspondiente al plan de suscripción seleccionado

  MODIFICAR DATOS DE ESTABLECIMIENTO : Use Case

 

El sistema permite al dueño del establecimiento editar y actualizar la ficha de su negocio o sedes registradas.

El usuario puede modificar aspectos clave como la razón social, fotos del local, horarios de apertura/cierre, números de contacto, redes sociales o la ubicación. Tras validar la coherencia de los cambios, el sistema refresca la información de forma inmediata en el catálogo público.

  CAMBIAR ESTADO ESTABLECIMIENTO (ACTIVAR/INACTIVAR) : Use Case

 

El sistema permite modificar el estado operativo de un establecimiento registrado dentro de la plataforma (ej. pasar de Activo a Inactivo / Suspendido y viceversa).

Al cambiar el estado a "Inactivo", el local se oculta automáticamente del catálogo público, bloqueando la recepción de nuevas reservas, sin eliminar su historial contable o de clientes en la base de datos.

  CONSULTAR DISPONIBILIDAD DE SERVICIOS : Use Case

 

El sistema despliega la lista consolidada de servicios configurados previamente por el local.

El usuario puede revisar el catálogo filtrando por categorías (ej. cortes, barba, combos), con el detalle de costo, tiempo estimado de atención, personal capacitado para realizarlo y si el servicio está activo para reservas.

  MODIFICAR SERVICIOS : Use Case

 

El sistema permite al dueño del establecimiento editar las propiedades de un servicio previamente registrado en el catálogo.

El usuario modifica los campos deseados (nombre, precio, duración en minutos, categoría o descripción) y el sistema valida los datos para actualizar la oferta en la plataforma.

  CAMBIAR ESTADO DE SERVICIOS : Use Case

El sistema permite modificar el estado de disponibilidad de un servicio registrado (ej. pasar de Activo a Inactivo / Pausado y viceversa).

  CONSULTAR EMPLEADOS REGISTRADOS : Use Case

 

El sistema despliega el listado completo de empleados y colaboradores registrados en la plataforma por el establecimiento.

El propietario puede visualizar el perfil de cada trabajador, consultar sus datos de contacto, especialidades de servicio, sede asignada y el estado actual de su cuenta (activo, inactivo o en vacaciones).

  MODIFICAR INFORMACION DE EMPLEADOS : Use Case

El propietario puede modificar campos como el teléfono, correo, especialidades, foto de perfil o la asignación de servicios que el trabajador puede ejecutar en el local.

  CAMBIAR ESTADO DE EMPLEADOS : Use Case

El sistema permite modificar el estado de un empleado registrado en el establecimiento (ej. pasar de Activo a Inactivo / Suspendido / Vacaciones y viceversa).

  CAMBIAR ESTADO DE CITA : Use Case

El sistema permite al dueño del establecimiento (o al personal con permisos) configurar y ajustar la jornada de atención semanal del local y los turnos individuales de cada trabajador.

  CAMBIAR PLAN DE SUSCRIPCION : Use Case

 

El sistema permite al dueño del establecimiento solicitar y procesar la modificación de su plan de suscripción actual dentro de la plataforma.

El propietario selecciona la nueva modalidad (ej. de Plan Básico a Premium), el sistema recalcula los cobros o prorrateos correspondientes, procesa la transacción financiera y actualiza de inmediato los límites y permisos de la cuenta del local.

  CAMBIAR ESTADO DE SUSCRIPCION : Use Case

El sistema permite al Superadministrador modificar el estado operativo de la suscripción de un establecimiento (ej. pasar de Activa a Suspendida, Cancelada o Inactiva por Mora, cambio de plan de suscripcion).

  RENOVAR SUSCRIPCION : Use Case

 

El sistema permite procesar la renovación del periodo de suscripción de un establecimiento para extender su fecha de vencimiento.

El proceso puede ejecutarse de forma automática mediante el cobro recurrente registrado por el Dueño en la pasarela de pagos o de forma manual por el Superadministrador tras verificar una transferencia o pago directo. Una vez validada la transacción, el sistema actualiza la fecha límite de servicio y mantiene la cuenta en estado Activa.

  CONSULTAR HISTORIAL DE PAGOS : Use Case

 

El sistema permite al dueño del establecimiento consultar el historial consolidado de transacciones financieras dentro de su panel administrativo.

Incluye la visualización de las facturas pagadas por la suscripción de su local y los pagos o reservas abonadas por sus clientes. Permite filtrar por fechas, estados de pago y descargar los comprobantes digitales en formato PDF.

  CAMBIAR ESTADO DE PAGOS (APROBAR/RECHAZAR) : Use Case

El sistema permite al Superadministrador (para pagos de suscripción) o al Dueño de Establecimiento (para abonos directos) cambiar el estado de una transacción financiera.

 

Permite transicionar un pago de estado Pendiente de Verificación a Aprobado o Rechazado, actualizando automáticamente el estado de la suscripción o de la cita asociada.

  VALIDAR REGLA CANCELACION ANTICIPADA : Use Case

 

El sistema valida en tiempo real la ventana de tiempo previa al servicio cuando un cliente intenta cancelar una cita.

Si faltan más de 5 horas para la cita, la cancelación se procesa de forma ordinaria. Si faltan menos de 5 horas, el sistema bloquea la anulación autónoma y aplica las restricciones correspondientes según la política del local.

  VALIDAR CONTROL DE CANCELACIONES MENSUALES : Use Case

 

El sistema lleva un contador dinámico del número de cancelaciones ejecutadas por cada cliente dentro del mes calendario vigente.

Si un cliente alcanza el límite máximo parametrizado por el negocio (ej. 3 cancelaciones al mes), el sistema restringe su capacidad para agendar nuevas citas de forma autónoma, exigiendo la intervención del personal o el dueño para levantar la sanción o solicitar un pago anticipado obligatorio.

  APLICAR SANCIÓN AUTOMÁTICA POR CANCELACIONES : Use Case

El sistema aplica de forma autónoma una sanción operativa o financiera al cliente cuando incurre en una cancelación tardía (menos de 5 horas, RF39) o sobrepasa el límite mensual de anulaciones (RF40).

Dependiendo de la configuración del local, la sanción puede consistir en la pérdida no reembolsable del anticipo, el cobro de una tarifa de penalización en la siguiente reserva o la inhabilitación temporal de la cuenta.        

  CONSULTAR ESTADO DE SANCION : Use Case

El sistema despliega el módulo informativo donde se detallan las sanciones activas o históricas aplicadas a un cliente por incumplimiento de las políticas de cancelación

El Cliente puede revisar la razón de su inhabilitación y el tiempo restante de suspensión; el Barbero puede verificar si un usuario cuenta con restricciones activas antes de agendarle un servicio manual; y el Dueño puede auditar el expediente para decidir si levanta la sanción.

  BLOQUEAR RESERVAS POR SANCIÓN : Use Case

El sistema restringe activamente la creación de nuevas reservas cuando un cliente con sanción vigente intenta iniciar un proceso de agendamiento

  REGISTRAR INASISTENCIA DE CLIENTE : Use Case

Al registrar la inasistencia, el sistema actualiza el estado de la reserva, libera la franja horaria en la agenda en tiempo real, retiene el anticipo correspondiente y suma una falta al expediente del cliente.

  REGISTRAR USUARIO : Use Case

El sistema permite a un usuario no registrado crear una cuenta en la plataforma Fresh Style ingresando sus datos personales obligatorios: nombres completos, correo electrónico, número telefónico, fecha de nacimiento y contraseña.

 

el sistema realiza validaciones automáticas para verificar que la información cumpla con los formatos requeridos y que el correo electrónico ingresado no se encuentre previamente registrado en la base de datos      . Una vez validada y almacenada la información, el usuario queda registrado correctamente y habilitado para iniciar sesión      .
