Description

 

El sistema permite al propietario generar y visualizar reportes analíticos básicos sobre la actividad de sus sedes y personal.

El usuario selecciona un rango de fechas y el tipo de reporte deseado (ventas, citas completadas, cancelaciones o ingresos por barbero), y el sistema procesa los datos para presentarlos en gráficos e indicadores consolidados exportables.

REPORTE DE ESTABLECIMIENTO
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al panel administrativo del negocio y selecciona la sección "Reportes y Estadísticas".
    • Elige el tipo de reporte a consultar (ej. "Ingresos del Mes", "Citas por Profesional", "Servicios más Vendidos").
    • Selecciona el periodo de análisis (semanal, mensual o un rango de fechas personalizado) y la sede correspondiente.
    • Presiona "Generar Reporte".
    • El sistema procesa los datos y despliega en pantalla los gráficos e indicadores analíticos.
    • Opcionalmente, el usuario exporta el informe en formato PDF o Excel.
■ Business Logic //LOGICA DE NEGOCIO
    • Solo se incluyen en los cálculos financieros y de rendimiento las citas registradas con estado "Completada" o "Pagada".
    • Las citas en estado "Cancelada" se contabilizan en una métrica independiente para medir la tasa de cancelación del local.
    • La información contable se consolida en tiempo real según las transacciones registradas en el sistema.
■ Decisions //DECISIONES
    • El acceso a reportes financieros avanzados o consolidados entre múltiples marcas queda reservado para planes de suscripción superiores.

REPORTES ESTABLECIMIENTO
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a la sección "Reportes y Estadísticas" => "Reportes Básicos".
2. Selecciona el tipo de reporte que desea consultar:
    2.1. Reporte de Citas (Atendidas, Canceladas e Inasistencias).
    2.2. Reporte de Ingresos / Facturación Estimada.
    2.3. Reporte de Desempeño por Barbero / Colaborador.
3. Define el rango de fechas (ej. Día actual, Semana, Mes o Rango personalizado) y presiona el botón "Generar Reporte".
4. El sistema consulta la base de datos para consolidar la información solicitada.
5. El sistema evalúa la existencia de registros para los criterios seleccionados:
    5.1. if no existen operaciones o registros en el periodo de tiempo indicado: El sistema muestra una alerta en pantalla con el mensaje "No hay datos registrados en el rango de fechas seleccionado para generar este reporte".
    5.2. else if El sistema procesa los indicadores básicos y despliega en pantalla los gráficos y tablas resumen correspondientes (Total citas, % de efectividad, Barbero con más atenciones e Ingresos acumulados).
        5.2.1. El sistema habilita la opción de exportar los datos.
        5.2.2. if el propietario presiona "Exportar (PDF / Excel)": El sistema genera el archivo en el formato elegido y dispara la descarga inmediata al dispositivo.
        5.2.3. else if El sistema mantiene el reporte visible en pantalla para consulta en línea.
               end if
         end if
