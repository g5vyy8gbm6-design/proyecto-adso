Use Case - CONSULTAR DISPONIBILIDAD DE ESTABLECIMIENTO link

Properties
Name Value
Description

 

El sistema permite al cliente explorar y verificar en tiempo real las franjas de tiempo libres para la atención de un servicio o profesional específico.

Tras seleccionar la sede, el servicio deseado y la fecha preferida, la plataforma procesa la matriz de horarios operativos y las citas previamente confirmadas para desplegar la agenda interactiva disponible.

 CONSULTAR DISPONIBILIDAD DE ESTABLECIMIENTO : Use Case

CLIENTE
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al perfil de un establecimiento o selecciona un servicio en el catálogo.
    • Selecciona la opción "Ver Agenda / Disponibilidad".
    • Elige una fecha en el calendario y opcionalmente filtra por un profesional de su preferencia.}
    • El sistema evalúa la disponibilidad y despliega los turnos habilitados en tiempo real.
    • El cliente selecciona la franja horaria conveniente para avanzar al proceso de reserva.
■ Business Logic //LOGICA DE NEGOCIO
    • La disponibilidad se calcula cruzando tres variables: el horario de atención de la sede, la agenda ocupada del personal y la duración estimada del servicio seleccionado
    • No se desplegarán franjas horarias que sobrepasen el horario de cierre del establecimiento.
    • El cálculo se realiza dinámicamente para prevenir bloqueos por compras simultáneas
■ Decisions //DECISIONES
    • Si el cliente no selecciona un profesional específico, el sistema muestra los bloques de tiempo en los que al menos un especialista de la sede se encuentre libre.

CLIENTE
Steps
1. El Cliente selecciona un servicio y un barbero específico (opcional) dentro de la ficha del establecimiento.
2. Navega al selector de fecha en el calendario interactivo.
3. El sistema consulta la base de datos cruzando los horarios de atención del local, los turnos laborales del barbero y las citas ya agendadas o bloqueadas para esa fecha.
4. El sistema evalúa el estado de la cuenta del cliente:
    4.1. if el cliente tiene una sanción activa o restricción por bloqueos: El sistema interrumpe la consulta, inhabilita el calendario y despliega el mensaje de restricción por penalización activa.
    4.2. else if El sistema evalúa los bloques de tiempo libres:
        4.2.1. if no existen franjas continuas de tiempo disponibles que cubran la duración total del servicio seleccionado para el día consultado: El sistema marca la fecha como "Sin Disponibilidad" y sugiere los días próximos con cupos libres.
        4.2.2. else if El sistema despliega las franjas horarias libres organizadas cronológicamente para que el cliente elija la hora de su cita.
               end if
         end if
