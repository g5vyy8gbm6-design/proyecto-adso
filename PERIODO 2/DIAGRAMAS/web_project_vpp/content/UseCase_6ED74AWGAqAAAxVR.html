Use Case - CONSULTAR HISTORIAL DE RESERVAS link

Properties
Name Value
Description

 

El sistema despliega el registro histórico de todas las citas agendadas por el cliente dentro de la plataforma.

La información se organiza de forma cronológica y permite filtrar entre citas activas/próximas, completadas, canceladas o no asistidas, mostrando detalles de fecha, hora, local, profesional, costo y comprobante digital.

 CONSULTAR HISTORIAL DE RESERVAS : Use Case

CLIENTE
■ Workflow //FLUJO DE TRABAJO
    • Accede a su perfil de usuario y selecciona la pestaña "Mis Reservas / Historial".
    • Aplica filtros opcionales (por rango de fechas, estado de la cita o establecimiento).
    • El sistema consulta la base de datos y presenta el listado de reservas de forma ordenada.
    • Selecciona una reserva específica para abrir el modal con el detalle completo de la atención.
    • Opcionalmente, interactúa con accesos directos como "Volver a Agendar" o "Ver Comprobante".
■ Business Logic //LOGICA DE NEGOCIO
    • El historial clasifica automáticamente cada registro según su ciclo de vida: Pendiente, En Proceso, Completada, Cancelada o No Asistió.
    • No se permite la eliminación de registros del historial para mantener la integridad del registro contable y operativo del sistema.
    • Las citas completadas habilitan un enlace directo para que el cliente pueda dejar una valoración/reseña del servicio.
■ Decisions //DECISIONES
    • Si el cliente no tiene reservas registradas, la interfaz despliega un mensaje informativo invitándolo a explorar el catálogo de establecimientos.

CLIENTE
Steps
1. El Cliente accede a su panel y navega a la sección "Historial de Citas / Reservas".
2. Selecciona la pestaña de filtro deseada (Todas, Finalizadas, Canceladas, Próximas).
3. El sistema consulta la base de datos y recupera las reservas asociadas a su cuenta.
4. El sistema evalúa la existencia de registros en el expediente del usuario:
    4.1. if el cliente no ha realizado reservas en la plataforma O no tiene citas en la categoría filtrada: El sistema muestra la vista vacía con el mensaje "No cuentas con historial de reservas registrado".
    4.2. else if El sistema despliega el listado cronológico de reservas mostrando: Fecha, Hora, Nombre del Establecimiento, Barbero asignado, Servicio prestado, Precio total y Estado (Completada, Cancelada, Inasistencia).
         end if
5. El cliente selecciona una cita completada para habilitar el botón de "Calificar Servicio" o reagendar un servicio frecuente.
