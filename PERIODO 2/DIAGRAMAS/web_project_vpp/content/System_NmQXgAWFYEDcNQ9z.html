Este paquete agrupa los casos de uso fundamentales encargados de validar la identidad de los usuarios y gestionar su información dentro de la plataforma Fresh Style      . Constituye la capa base de seguridad y personalización del sistema, permitiendo:     

  • Control de acceso y seguridad: Garantiza que únicamente los usuarios autenticados puedan interactuar con las funcionalidades del sistema según su rol      .     

  • Gestión de identidad: Facilita el alta de nuevos usuarios (RF01)      , la validación de credenciales (RF02)      y el restablecimiento seguro de claves (RF03)      .     

  • Personalización y trazabilidad: Permite a los usuarios actualizar sus datos personales (RF04)      y consultar restricciones o sanciones asociadas a su cuenta (RF42)      , asegurando la integridad de los datos e historial del usuario      .

 REGISTRAR USUARIO : Use Case

El sistema permite a un usuario no registrado crear una cuenta en la plataforma Fresh Style ingresando sus datos personales obligatorios: nombres completos, correo electrónico, número telefónico, fecha de nacimiento y contraseña.

 

el sistema realiza validaciones automáticas para verificar que la información cumpla con los formatos requeridos y que el correo electrónico ingresado no se encuentre previamente registrado en la base de datos      . Una vez validada y almacenada la información, el usuario queda registrado correctamente y habilitado para iniciar sesión      .                

 INICIAR SESION : Use Case

El sistema permite a un usuario previamente registrado acceder a la plataforma web mediante el ingreso de sus credenciales de acceso: correo electrónico y contraseña.  

el sistema valida las credenciales contra la base de datos      . Si la información es correcta, genera una sesión activa y redirige al usuario al panel de control correspondiente a su rol      . En caso de credenciales incorrectas o cuenta inactiva/suspendida, el sistema bloquea el acceso y muestra un mensaje informativo      . 

 RECUPERAR CONTRASEÑA : Use Case

El sistema permite a un usuario registrado solicitar el restablecimiento de su clave de acceso ingresando el correo electrónico asociado a su cuenta      . 

 

Tras verificar la existencia del correo en la base de datos, el sistema genera y envía un enlace o token de recuperación seguro con un tiempo de caducidad limitado      . El usuario accede al enlace recibido, ingresa una nueva contraseña cumpliendo con las políticas de seguridad y confirma el cambio, quedando habilitado inmediatamente para iniciar sesión con la nueva credencial      .

 MODIFICAR PERFIL : Use Case

El sistema permite a cualquier usuario autenticado acceder a la configuración de su cuenta para consultar y actualizar sus datos personales (como nombre, teléfono, fecha de nacimiento o contraseña)      . 

 

El usuario modifica los campos deseados y envía el formulario; el sistema valida el formato de los datos ingresados y guarda los cambios en la base de datos      . En caso de requerir la modificación de credenciales sensibles, se aplican confirmaciones de seguridad adicionales      .

 CONSULTAR ESTADO DE SANCION : Use Case

El sistema despliega el módulo informativo donde se detallan las sanciones activas o históricas aplicadas a un cliente por incumplimiento de las políticas de cancelación

El Cliente puede revisar la razón de su inhabilitación y el tiempo restante de suspensión; el Barbero puede verificar si un usuario cuenta con restricciones activas antes de agendarle un servicio manual; y el Dueño puede auditar el expediente para decidir si levanta la sanción.
