ESTABLECMIENTO MODIFICA EMPLEADOS
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al panel de administración y navega a "Gestión de Personal / Empleados"
    • Selecciona al trabajador objetivo y presiona la opción "Editar / Modificar".
    • Modifica los campos deseados (ej. agregar una nueva especialidad, cambiar teléfono o actualizar foto).
    • Presiona "Guardar Cambios".
    • El sistema valida la consistencia de los datos y actualiza el registro en la base de datos.
■ Business Logic //LOGICA DE NEGOCIO
    • Si se desvincula un servicio del perfil de un empleado, el sistema verificará que el profesional no tenga citas pendientes agendadas para dicho servicio.
    • Los cambios en la información de contacto o especialidades del personal se reflejan de inmediato en la vista del cliente durante el proceso de reserva
    • No se permite modificar el número de documento de identidad del trabajador sin una validación administrativa directa.
■ DecisioS //DECISIONES
    • Si la modificación implica cambiar el correo electrónico del empleado, el sistema enviará un enlace de verificación al nuevo correo para validar el acceso a la cuenta.

(ACTUALIZACIÓN DE FICHA DEL COLABORADOR)
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a "Gestión de Personal" => "Lista de Empleados"
2. Selecciona un colaborador de la nómina y hace clic en la opción "Editar / Modificar Empleado".
3. El sistema despliega el formulario prellenado con los datos actuales del barbero (Nombres, Apellidos, Teléfono, Correo electrónico, Porcentaje/Esquema de comisión y Foto de perfil).
4. El propietario realiza los cambios requeridos en la información general del profesional y presiona el botón "Guardar Cambios".
5. El sistema evalúa la validez de los datos ingresados:
    5.1. if el correo electrónico ingresado pertenece a otro usuario registrado en la plataforma O los campos obligatorios de identificación están vacíos:
        5.1.1. El sistema frena la actualización y notifica "El correo electrónico ya se encuentra en uso por otro perfil o existen campos obligatorios sin diligenciar".
    5.2. else if
        5.2.1. El sistema actualiza los datos del empleado en la base de datos de la sede.
        5.2.2. El sistema refresca la información visible en la ficha pública del establecimiento para los clientes y despacha la notificación de actualización al correo del colaborador
         end if
    5.3.

(MODIFICACIÓN DE SERVICIOS Y HABILIDADES ASIGNADAS)
Steps
1. El Dueño de Establecimiento selecciona la pestaña "Servicios Asignados" dentro de la edición del empleado.
2. Marca o desmarca del catálogo de la sede los cortes o tratamientos que el profesional está capacitado para realizar.
3. Presiona el botón "Actualizar Servicios del Empleado".
4. El sistema evalúa el impacto de la desasignación de servicios contra la agenda del barbero:
    4.1. if el propietario intenta quitar un servicio para el cual el barbero ya tiene citas futuras confirmadas en su agenda
        4.1.1. El sistema emite una advertencia de bloqueo: "No se puede desasignar el servicio '[Nombre del Servicio]' porque el colaborador tiene [N] citas confirmadas pendientes para atenderlo. Reasigne las citas o espere a que se completen".
    4.2. else if El sistema actualiza los permisos del colaborador y ajusta la matriz de disponibilidad para las reservas de los clientes
         end if
