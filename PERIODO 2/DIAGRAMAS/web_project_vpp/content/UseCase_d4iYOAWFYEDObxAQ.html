Description

 

El sistema despliega el listado completo de empleados y colaboradores registrados en la plataforma por el establecimiento.

El propietario puede visualizar el perfil de cada trabajador, consultar sus datos de contacto, especialidades de servicio, sede asignada y el estado actual de su cuenta (activo, inactivo o en vacaciones).

 CONSULTAR EMPLEADOS REGISTRADOS : Use Case

(CONSULTA Y FILTRADO DEL EQUIPO DE TRABAJO)
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a "Gestión de Personal" => "Lista de Empleados".
2. El sistema consulta en la base de datos la nómina de colaboradores vinculados exclusivamente a la sede seleccionada.
3. El propietario puede aplicar filtros de búsqueda (por Nombre, Número de Documento, Estado: Activo/Inactivo o Servicio Asignado).
4. El sistema evalúa el resultado de la consulta sobre la nómina:
    4.1. if el establecimiento no cuenta con colaboradores registrados O el filtro aplicado no devuelve ninguna coincidencia:
        4.1.1. El sistema despliega una vista vacía con el mensaje "No se encontraron empleados o colaboradores registrados que coincidan con la búsqueda" y ofrece un botón de acceso directo para registralos .
    4.2. else if El sistema presenta la lista de empleados organizados en una tabla interactiva mostrando: Foto de perfil, Nombre completo, Documento, Teléfono, Correo, Servicios que presta, Estado actual (Activo / Inactivo) y accesos rápidos para Modificar o Cambiar Estado.
         end if

(CONSULTA DEL DETALLE DE UN EMPLEADO)
Steps
1. El Dueño de Establecimiento selecciona un colaborador específico de la lista (Flujo consulta y filtrado del equipo) y presiona "Ver Ficha Detallada".
2. El sistema recupera el expediente completo del profesional desde la base de datos.
3. El sistema evalúa la disponibilidad de métricas del empleado:
    3.1. if el empleado está recién registrado y aún no posee atenciones realizadas ni horarios configurados:
        3.1.1. El sistema muestra sus datos personales básicos acompañados de un aviso informativo "El colaborador no registra historial de citas ni métricas de desempeño aún".
    3.2. else if El sistema despliega el expediente completo integrando: Datos de contacto, Horario semanal asignado, Servicios asociados, Calificación promedio recibida por clientes y total de citas completadas.
         end if
