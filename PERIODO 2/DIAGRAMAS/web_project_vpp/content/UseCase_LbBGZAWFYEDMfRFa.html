Description

 

El sistema permite al dueño del establecimiento consultar el historial consolidado de transacciones financieras dentro de su panel administrativo.

Incluye la visualización de las facturas pagadas por la suscripción de su local y los pagos o reservas abonadas por sus clientes. Permite filtrar por fechas, estados de pago y descargar los comprobantes digitales en formato PDF.

 CONSULTAR HISTORIAL DE PAGOS : Use Case

Use Case Note
■ Workflow //FLUJO DE TRABAJO
    • El Dueño de Establecimiento ingresa a su panel y navega a "Configuración del Negocio" => "Historial de Pagos y Facturación".
    • El sistema despliega el listado cronológico de pagos realizados (suscripciones de la plataforma) e ingresos procesados.
    • Utiliza los filtros para buscar por rango de fechas, estado de la transacción (Aprobado, Pendiente, Rechazado) o concepto.
    • Selecciona una transacción específica para ver el detalle de la pasarela de pago.
    • Presiona el botón "Descargar Comprobante" para obtener la factura digital.
■ Business Logic //LOGICA DE NEGOCIO
    • Los registros de pago son de solo lectura y no pueden ser modificados ni eliminados por el dueño para garantizar la integridad contable.
    • Cada registro debe mostrar: ID de referencia, fecha/hora, concepto (ej. Renovación Suscripción Plan Pro o Abono Reserva), monto total, estado del pago y método utilizado (tarjeta, transferencia, etc.).
    • El Superadministrador cuenta con una vista global equivalente para auditar los pagos de todos los establecimientos registrados.
■ Decisions //DECISIONES
    • Si una transacción figura en estado Pendiente por más de 24 horas (ej. pago por PSE o transferencia no conciliada), el sistema mostrará un botón de "Verificar Estado" para consultar en tiempo real con la pasarela de pagos.

(CONSULTA Y DESCARGA DE COMPROBANTES DE SUSCRIPCIÓN)
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a "Mi Suscripción" => "Historial de Pagos".
2. El sistema consulta en la base de datos el historial de transacciones, cobros y comprobantes asociados al establecimiento.
3. El propietario puede aplicar filtros de búsqueda (por Rango de fechas, Estado del pago: Aprobado / Rechazado / Pendiente o Método de pago).
4. El sistema evalúa el resultado de la consulta sobre el historial:
    4.1. if el establecimiento no registra ninguna transacción previa O los filtros aplicados no arrojan resultados:
        4.1.1. El sistema despliega una vista sin registros con el mensaje "No se encontraron pagos registrados en el historial para este establecimiento".
    4.2. else if El sistema presenta la lista cronológica de pagos mostrando: Fecha de transacción, Plan contratado, Valor cobrado, Método de pago utilizado, Estado del pago (Aprobado, Rechazado, Pendiente de Verificación) y el número de referencia.
         end if
5. El propietario hace clic en la opción "Ver Recibo / Descargar Factura" de un pago específico en estado Aprobado.
6. El sistema evalúa la disponibilidad del documento:
    6.1. if la factura digital o comprobante PDF está generado correctamente en el servidor:
        6.1.1. El sistema descarga la factura digital en PDF o la proyecta en pantalla para su impresión.
    6.2. else if
        6.2.1. El sistema muestra la alerta "El recibo digital está en proceso de generación. Por favor, intente de nuevo en unos minutos".
         end if
