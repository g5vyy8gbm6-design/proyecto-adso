Description

 

El sistema permite al dueño del establecimiento editar las propiedades de un servicio previamente registrado en el catálogo.

El usuario modifica los campos deseados (nombre, precio, duración en minutos, categoría o descripción) y el sistema valida los datos para actualizar la oferta en la plataforma.

 MODIFICAR SERVICIOS : Use Case

MODIFICA LOS SERVICIOS
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al panel de administración y navega a la sección "Gestión de Servicios".
    • Ubica el servicio a ajustar y selecciona la opción "Editar / Modificar".
    • Cambia los valores en el formulario (ej. actualización de precio o ajuste de tiempo de atención).
    • Presiona "Guardar Cambios".
    • El sistema valida la consistencia de los datos e ingresa las actualizaciones a la base de datos.
■ Business Logic //LOGICA DE NEGOCIO
    • La actualización del precio o la duración de un servicio no modifica las citas registradas ni confirmadas con anterioridad; solo aplica para nuevas reservas.
    • El valor de duración debe ser un número entero positivo mayor a cero (medido en minutos) para no alterar el algoritmo de agendamiento.
    • Los cambios en el catálogo se reflejan en tiempo real en la consulta pública de servicios
■ Decisions //DECISIONES
    • Si el propietario intenta cambiar la duración de un servicio a un tiempo menor al bloque mínimo del sistema (ej. menos de 15 minutos), el sistema mostrará un mensaje de alerta impidiendo el guardado.
    •

(ACTUALIZACIÓN DE PARÁMETROS DE UN SERVICIO)
Steps
1. El Dueño de Establecimiento ingresa a su panel de administración y navega a "Catálogo de Servicios".
2. Selecciona un servicio existente de la lista y hace clic en la opción "Editar / Modificar Servicio".
3. El sistema despliega el formulario prellenado con la información actual del servicio (Nombre, Descripción, Precio, Duración estimada en minutos, Categoría y Foto ilustrativa).
4. El propietario realiza los cambios deseados y presiona el botón "Guardar Cambios".
5. El sistema evalúa la validez de los datos modificados:
    5.1. if el campo de nombre o precio está vacío, el valor ingresado es menor o igual a cero, O la duración es cero:
        5.1.1. El sistema bloquea la actualización y notifica "El precio y la duración deben ser valores numéricos mayores a cero, y el nombre es obligatorio".
    5.2. else if
        5.2.1. El sistema evalúa el impacto del cambio en la duración del servicio:
            5.2.1.1. if el propietario incrementó la duración en minutos del servicio Y existen citas futuras agendadas con la duración previa para este servicio:
                    El sistema emite una advertencia de confirmación: "Atención: El cambio de duración aplicará únicamente para nuevas reservas. Las citas confirmadas previamente mantendrán el bloque de tiempo original contratado".
            5.2.1.2. else if El sistema actualiza los datos del servicio en la base de datos de la sede.
                5.2.1.2.1. El sistema refresca la información visible en el catálogo público del negocio de cara a los clientes y envía la notificación de confirmación al correo del propietario
                     end if
         end if
