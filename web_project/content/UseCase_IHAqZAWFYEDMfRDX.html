Use Case - RENOVAR SUSCRIPCION link

Properties
Name Value
Description

 

El sistema permite procesar la renovación del periodo de suscripción de un establecimiento para extender su fecha de vencimiento.

El proceso puede ejecutarse de forma automática mediante el cobro recurrente registrado por el Dueño en la pasarela de pagos o de forma manual por el Superadministrador tras verificar una transferencia o pago directo. Una vez validada la transacción, el sistema actualiza la fecha límite de servicio y mantiene la cuenta en estado Activa.

SUPERADMIN
■ Workflow //FLUJO DE TRABAJO (AUTOMATICO)
    • Llegada la fecha de corte, el sistema invoca la pasarela de pagos para ejecutar el cobro recurrente registrado.
    • Si el cobro es exitoso, la pasarela notifica al sistema.
    • El sistema calcula la nueva fecha de vencimiento (añade 30 días o 1 año) y genera el recibo digital.
■ Workflow //FLUJO DE TRABAJO (MANUAL)(SUPERADMIN)
    • El Superadministrador ingresa al módulo global de suscripciones y busca el establecimiento.
    • Selecciona la opción "Registrar Renovación Manual".
    • Ingresa el comprobante de pago, periodo a renovar (meses/años) y valor abonado.
    • Presiona "Confirmar Renovación".
    • El sistema extiende la vigencia de la membresía y remite la notificación al propietario.
■ Business Logic //LOGICA DE NEGOCIO
    • La nueva fecha de vencimiento se calcula tomando como base la fecha de vencimiento anterior (si el pago fue oportuno) o la fecha actual (si la cuenta se encontraba en estado inactivo o en periodo de gracia).
    • Si la cuenta se encontraba suspendida por mora, la confirmación de la renovación cambia inmediatamente el estado de la suscripción a Activa y restituye los servicios públicos del local.
    • El sistema envía alertas automáticas al Dueño 7, 3 y 1 día(s) antes del vencimiento para prevenir la interrupción del servicio.
■ Decisions //DECISIONES
    • Si el cobro automático falla por fondos insuficientes o tarjeta vencida, el sistema cambia la cuenta a estado "En Periodo de Gracia" (ej. 3 a 5 días) y le notifica al propietario para que actualice su método de pago o realice el pago manual antes de suspender los servicios.

(RENOVACIÓN MANUAL / EXTENSIÓN ADMINISTRATIVA)
Steps
1. El Superadministrador ingresa a la consola global y navega a "Gestión de Suscripciones" =>
2. "Suscripciones Próximas a Vencer / Vencidas".Selecciona un establecimiento específico y presiona la opción "Procesar Renovación Manual" (tras validar el pago en RF38 o por concesión comercial).
3. Ingresa los meses/días a renovar y la justificación del registro.
4. El sistema evalúa el estado previo de la suscripción del negocio:
    4.1. if la suscripción se encontraba en estado Suspendida o Inactiva por mora
        4.1.1. El sistema cambia el estado a Activa, reactiva automáticamente la visibilidad pública de la sede y calcula la nueva fecha límite de cobertura.
    4.2. else if (La suscripción estaba Activa):
        4.2.1. El sistema añade el tiempo contratado a la fecha de vencimiento futura acumulada.
         end if
5. El sistema envía la notificación de renovación exitosa al correo del propietario

(RECORDATORIO AUTOMÁTICO DE RENOVACIÓN)
Steps
1. El Sistema ejecuta la rutina periódica de revisión de vencimientos.
2. Compara la fecha actual contra las fechas de expiración de todos los establecimientos.
3. El sistema evalúa los días restantes para el vencimiento:
    3.1. if faltan 7, 3 o 1 día(s) para el vencimiento de la suscripción Y no hay un pago registrado pendiente de validación:
        3.1.1. El sistema despacha una notificación de alerta recordatoria al propietario indicando la fecha límite y el enlace directo para renovar
    3.2. else if El sistema no realiza ninguna acción.
         end if
