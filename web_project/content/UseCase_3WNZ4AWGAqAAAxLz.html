PANEL DE RESERVAS : System

Use Case - MODIFICAR RESERVA ACTIVAS link

Properties
Name Value
Description

 

El sistema permite al cliente reprogramar la fecha, hora o el profesional asignado a una cita agendada previamente.

 

La plataforma valida que la modificación se realice dentro de los plazos temporales permitidos por las políticas del negocio, libera el espacio anterior en la agenda y reagenda el servicio en la nueva franja horaria seleccionada.

CLIENTE
■ Workflow //FLUJO DE TRABAJO
    • Ingresa a la sección "Mis Citas / Historial de Reservas" dentro de su cuenta.
    • Selecciona la cita activa que desea reprogramar y presiona "Modificar Cita".
    • El sistema despliega la agenda con los nuevos turnos y profesionales disponibles.
    • Selecciona la nueva fecha y hora.
    • Confirma la reprogramación y el sistema actualiza el registro en la base de datos.
    • Se envían las notificaciones automáticas de actualización.
■ Business Logic //LOGICA DE NEGOCIO
    • Solo se permite modificar citas que se encuentren en estado "Confirmada" o "Pendiente de Atención".
    • La modificación está sujeta a un límite de tiempo anticipado (ej. máximo hasta 5 horas antes de la cita) según las políticas del local.
    • Al confirmar el cambio, la franja horaria original se libera inmediatamente para otros usuarios y se bloquea el nuevo horario.
■ Decisions //DECISIONES
    • Si el intento de cambio se realiza fuera del rango de tiempo permitido, el sistema bloquea la acción y sugiere al cliente comunicarse directamente con el establecimiento.

PERSONAL PROFESIONAL
■ Workflow //FLUJO DE TRABAJO
    • Ingresa a su panel de agenda diaria, ubica la reserva del cliente y presiona "Reagendar / Modificar".
    • El sistema carga la agenda y permite elegir un nuevo bloque de fecha/hora o modificar el servicio.
    • El sistema valida que el nuevo horario esté totalmente libre en la agenda del barbero y se envia una notificacion automatica al cliente dandole las 2 opciones marcadas por el barbero
    • Se confirman los cambios y se reescriben los detalles en la base de datos.
    • Se despacha una notificación de actualización a la otra parte interesada.
■ Business Logic //LOGICA DE NEGOCIO
    • El barbero puede modificar sus citas con 1 hora de antelacion de lo contrario no
    • No se permite modificar citas que ya se encuentren en estado Completada, Cancelada o No Asistió.
    • Si la modificación implica un cambio de precio por cambio de servicio, el sistema recalcula el total a pagar.
■ DecisionS //DECISIONES
    • Si el nuevo bloque de tiempo seleccionado por el cliente o barbero entra en conflicto con otra reserva existente, el sistema bloquea la acción y sugiere el horario disponible más cercano.

CLIENTE PANEL CITAS
Steps
1.
2. El Cliente accede a la sección "Mis Citas" en la plataforma web o aplicación móvil.
3. Selecciona una cita previamente agendada en estado Confirmada y presiona el botón "Reagendar / Modificar Cita".
4. El sistema valida el margen de tiempo previo a la cita:
    4.1. if el tiempo restante para la cita es menor al límite establecido por el local (ej. menos de 5 horas previo a la atención) El sistema frena el proceso, deshabilita la opción de edición y muestra el mensaje "Las citas solo pueden ser modificadas con más de 5 horas de anticipación. Contacte directamente al establecimiento".
    4.2. else if El sistema habilita el calendario y despliega la consulta de disponibilidad en tiempo real
        4.2.1. El cliente selecciona la nueva fecha, franja horaria o cambio de barbero.
        4.2.2. El sistema evalúa si la nueva franja elegida se encuentra libre:
            4.2.2.1. if la fecha/hora seleccionada presenta un conflicto de agendamiento: El sistema notifica "El horario seleccionado ya no está disponible, elija otra opción".
            4.2.2.2. else if El sistema reasigna la cita a la nueva fecha y hora, actualiza la base de datos y despacha la notificación automática con los nuevos detalles del turno
                     end if
         end if

PERSONAL MODIFICA CITA
Steps
1. El Personal / Barbero abre su agenda de trabajo, ubica la cita del cliente y presiona la opción "Mover Cita".
2. Selecciona un nuevo bloque de tiempo libre en su agenda o transfiere la cita a la agenda de otro barbero de la misma sede previa consulta con el cliente.
3. El sistema evalúa el cruce de horarios en el destino elegido:
    3.1. if la franja horaria de destino en la agenda seleccionada ya se encuentra ocupada: El sistema notifica la sobreposición de agendas y solicita elegir un espacio libre
    3.2. else if El sistema efectúa la modificación en el panel operativo, ajusta la franja del profesional y envía la alerta de reprogramación al correo y teléfono del cliente
         end if
