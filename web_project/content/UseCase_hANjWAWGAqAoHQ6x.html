Use Case - BUSCAR ESTABLECIMIENTOS CERCANOS link

Description

 

El sistema utiliza las coordenadas geográficas en tiempo real del dispositivo del cliente para calcular y ordenar los establecimientos más cercanos a su ubicación actual.

La plataforma calcula la distancia lineal entre la posición del usuario y las sedes registradas, desplegando un listado priorizando el margen de proximidad en kilómetros o metros.

 BUSCAR ESTABLECIMIENTOS CERCANOS : Use Case

BUSQUEDA REDUCIDA
■ Workflow //FLUJO DE TRABAJO
    • Accede al módulo de exploración o presiona la opción "Cerca de mí".
    • El sistema solicita acceso a los permisos de ubicación/GPS del dispositivo.
    • Tras otorgar el permiso, el sistema obtiene la latitud y longitud actuales del usuario.
    • Se ejecuta el cálculo de proximidad sobre las sedes activas en la base de datos.
    • El sistema presenta la lista de establecimientos ordenados descendentemente por distancia (de menor a mayor recorrido).
■ Business Logic //LOGICA DE NEGOCIO
    • El cálculo de distancia se realiza aplicando la fórmula de Haversine entre la posición del dispositivo y las coordenadas fijas del local (RF05/RF07).
    • Solo se incluyen en los resultados las sedes marcadas como "Activas".
    • Se define un radio de cobertura máximo por defecto (ej. 10 km) que el usuario puede expandir según sus preferencias.
■ Decisions //DECISIONES
    • Si el usuario rechaza los permisos de geolocalización, el sistema solicita ingresar manualmente el barrio o municipio para realizar la aproximación.

BUSQUEDA CERCANA
Steps
1. El Cliente accede a la sección de búsqueda en la plataforma y activa el filtro de ordenamiento o vista "Cercanos a mí".
2. El sistema solicita la lectura de la posición actual del dispositivo vía GPS / Geolocalización web.
3. El sistema evalúa la disponibilidad del servicio de localización:
    3.1. if el cliente rechaza los permisos de geolocalización o la señal de GPS falla: El sistema muestra la alerta "No fue posible obtener tu ubicación actual. Selecciona una ciudad o ingresa una dirección manualmente".
        3.1.1. if el cliente ingresa una dirección de referencia manual:El sistema la geocodifica a coordenadas ($Lat, Long$) y continúa el proceso desde ese punto de referencia.
        3.1.2. else if El sistema interrumpe la búsqueda por cercanía y regresa al listado general de búsqueda
        3.1.3. else if (Ubicación obtenida exitosamente):
            3.1.3.1. El cliente selecciona un radio de búsqueda (ej. 1 km, 3 km, 5 km o 10 km alrededor).
            3.1.3.2. El sistema calcula las distancias relativas mediante la fórmula de Haversine cruzando la posición del usuario contra la base de datos.
            3.1.3.3. El sistema evalúa el estado y la distancia de cada local:
            3.1.3.4. if un establecimiento está a una distancia mayor al radio seleccionado O se encuentra en estado Inactivo, Suspendido o Cancelado: El sistema descarta el local de la lista de resultados.
            3.1.3.5. else if (Establecimientos Activos dentro del radio de cobertura):El sistema genera y presenta la lista de locales ordenados de menor a mayor distancia (ej. "a 300 metros", "a 1.2 km"), incluyendo tiempo estimado de llegada, calificación promedio (RF18) y acceso a reservas
                     end if
               end if
         end if
