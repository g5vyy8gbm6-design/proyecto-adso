Description

El sistema permite al propietario dar de alta, modificar y administrar las diferentes sedes físicas pertenecientes a su marca o empresa.

El usuario configura la dirección específica, teléfono directo, horarios particulares y estado operativo de cada sucursal, permitiendo que los clientes seleccionen la sede más cercana al momento de reservar.

 CONSULTAR MIS ESTABLECIMIENTOS : Use Case

ESTABLECIMIENTO (DUEÑO)
■ Workflow // FLUJO DE TRABAJO
    • Navega al módulo "MIS ESTABLECIMIENTOS" en su panel de control.
    • Selecciona "Agregar Nueva Sede" o elige una sede existente para modificar sus parámetros.
    • Ingresa o actualiza la dirección específica, geolocalización, teléfono de contacto directo y horarios de funcionamiento de la sucursal.
    • Asigna o ajusta el estado operativo de la sede (Activa / Inactiva temporalmente).
    • Guarda la información y el sistema confirma el registro o actualización de la sucursal.
■ Business Logic // LOGICA DE NEGOCIO
    • Cada sede debe contar con un identificador único y una dirección física validada para evitar duplicados.
    • La desactivación de una sede específica no inactiva la cuenta general del negocio ni a las demás sucursales.
    • Los profesionales y servicios del negocio se vinculan a una o varias sedes específicas para controlar el agendamiento.
■ Decisions // DECISIONES
    • El límite de sedes permitidas a registrar dependerá del plan de suscripción activo del Dueño de Establecimiento.
    • Si una sede se inactiva, se notificará a los clientes con reservas programadas en dicha ubicación para su reprogramación.

Scenario
Steps
1. El Dueño de Establecimiento ingresa a su panel y selecciona "Mis Establecimientos / Sedes".
2. El sistema consulta las sedes vinculadas al ID del propietario en la base de datos.
3. El sistema evalúa la existencia de registros asociados:
    3.1. if el propietario no tiene sedes registradas aún (ej. usuario nuevo): El sistema muestra la pantalla de bienvenida e invita a registrar la primera sede
    3.2. else if El sistema presenta la lista de sus locales especificando: Estado operativo (Activo/Inactivo), Estado de la suscripción, Barberos activos y Accesos directos a la configuración de cada sede.
         end if
