Use Case - VALIDAR REGLA CANCELACION ANTICIPADA link

Properties
Name Value
Description

 

El sistema valida en tiempo real la ventana de tiempo previa al servicio cuando un cliente intenta cancelar una cita.

Si faltan más de 5 horas para la cita, la cancelación se procesa de forma ordinaria. Si faltan menos de 5 horas, el sistema bloquea la anulación autónoma y aplica las restricciones correspondientes según la política del local.

CLIENTE
■ Workflow //FLUJO DE TRABAJO
    • Intenta cancelar una cita activa desde la sección "Mis Citas".
    • El sistema calcula la hora actual con la hora de la cita
    • Si la hora cita es mayor a 5h que la hora actual permite cancelar la cita
    • si la hora cita es menor o igual a 5h que la hora actual bloquea la cancelacion automatica,
■ Business Logic //LOGICA DE NEGOCIO
    • La restricción de 5 horas aplica de forma estricta únicamente para el rol Cliente. Los roles Personal y Dueño tienen permisos de anulación inmediata sin importar el tiempo restante.
    • El cliente no podra cancelar por menos de 5 horas de la cita
■ Decisions //DECISIONES
    • Si el cliente se encuentra dentro del rango extemporáneo el sistema le permitirá enviar una "Solicitud de Cancelación Excepcional" que le llegará como notificación al barbero para que este decida si la aprueba o no.

PERSONAL/PROFESIONAL
■ Workflow //FLUJO DE TRABAJO
    • Accede a su agenda diaria y selecciona una cita dentro de las próximas 5 horas antes de la cita.
    • Presiona "Cancelar Cita por Excepción".
    • El sistema omite la restricción de las 5 horas, solicita la causa (ej. falla técnica, enfermedad, acuerdo directo con cliente) y ejecuta la anulación liberando la agenda.
■ Business Logic //LOGICA DE NEGOCIO
    • La restricción de 5 horas aplica de forma estricta únicamente para el rol Cliente. Los roles Personal y Dueño tienen permisos de anulación inmediata sin importar el tiempo restante.
    • El personal/profesional no podra cancelar por menos de 5 horas de la cita
■ Decisions //DECISIONES
    • Si el personal profesional se encuentra dentro del rango extemporáneo el sistema le permitirá enviar una "Solicitud de Cancelación Excepcional" que le llegará como notificación al cliente para que este decida si la aprueba o no.

(SOLICITUD DE CANCELACIÓN DE CITA POR PARTE DEL CLIENTE)
Steps
1. El Cliente ingresa a su panel de usuario, navega a "Mis Citas / Historial" (RF15) y selecciona una cita activa en estado Confirmada o Pendiente.
2. El Cliente presiona el botón "Solicitar Cancelación".
3. El sistema obtiene la Fecha y Hora Actual del Servidor y la compara contra la Fecha y Hora de Inicio Programada de la cita.
4. El sistema calcula la diferencia horaria
5. El sistema evalúa la ventana de tiempo de cancelación:
    5.1. if el tiempo restante es mayor o igual a 5 horas
        5.1.1. El sistema cambia el estado de la cita a "Cancelada por el Cliente"
        5.1.2. El sistema libera inmediatamente el bloque de disponibilidad en la agenda del barbero y en el calendario del establecimiento.
        5.1.3. El sistema registra el motivo de la cancelación ingresado por el usuario.
        5.1.4. El sistema procesa la devolución o liberación de créditos/pago previo (según la política del establecimiento).
        5.1.5. El sistema notifica la cancelación confirmada al cliente y al profesional asignado
    5.2. else if
        5.2.1. El sistema bloquea el flujo directo de cancelación gratuita y despliega la pantalla de advertencia: "Faltan menos de 5 horas para tu cita. Aplica la política de cancelación tardía".
        5.2.2. El sistema evalúa la confirmación del usuario para proceder con la restricción:
            5.2.2.1. if el Cliente acepta continuar con la cancelación sabiendo que incurre en la penalización de la reserva (pérdida del anticipo o cobro de tarifa de cancelación):
                5.2.2.1.1. El sistema cambia el estado de la cita a "Cancelada Tardía con Penalización".
                5.2.2.1.2. El sistema libera la franja horaria en la agenda del colaborador
                5.2.2.1.3. El sistema notifica de inmediato al establecimiento y al barbero la cancelación de último minuto
            5.2.2.2. else if (El Cliente cancela la operación de anulación):
                5.2.2.2.1. El sistema interrumpe el proceso y mantiene la cita en su estado original (Confirmada).
                     end if
         end if

(CANCELACIÓN EXCEPCIONAL POR EL DUEÑO DE ESTABLECIMIENTO O BARBERO)
Steps
1. El Dueño de Establecimiento o el Personal/Profesional accede a la agenda operativa (RF13) y selecciona una cita agendada por un cliente.
2. Presiona la opción "Cancelar Cita de Cliente".
3. El sistema evalúa el rol que ejecuta la acción:
    3.1. if la cancelación es efectuada directamente por el establecimiento o el barbero (por motivo de fuerza mayor, enfermedad o cierre de emergencia):
        3.1.1. El sistema omite la restricción de las 5 horas y asigna el estado "Cancelada por el Local".
        3.1.2. El sistema libera la agenda y no aplica ninguna penalización al cliente.
        3.1.3. El sistema notifica urgentemente al cliente por correo y push informando el motivo del establecimiento
    3.2. else if
        3.2.1. El sistema aplica la regla estándar del Flujo Principal.
         end if
