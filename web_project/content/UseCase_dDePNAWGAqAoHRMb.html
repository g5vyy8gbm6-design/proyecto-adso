Description

El sistema despliega el módulo informativo donde se detallan las sanciones activas o históricas aplicadas a un cliente por incumplimiento de las políticas de cancelación

El Cliente puede revisar la razón de su inhabilitación y el tiempo restante de suspensión; el Barbero puede verificar si un usuario cuenta con restricciones activas antes de agendarle un servicio manual; y el Dueño puede auditar el expediente para decidir si levanta la sanción.

Use Case Note
■ Workflow //FLUJO DE TRABAJO
    • Accede a su perfil en la sección "Mis Sanciones / Estado de Cuenta".
    • El sistema verifica el estado del perfil. Si tiene un bloqueo activo, le muestra una tarjeta informativa destacada.
    • Visualiza la cita que originó la falta, el motivo (ej. "Cancelación fuera del tiempo límite de 5 horas"), el tipo de penalización (retención de abono o inhabilitación temporal) y la fecha/hora exacta en que volverá a estar activo.
    • Si la política lo permite, presiona la opción "Solicitar Apelación / Contactar Soporte".
■ Business Logic //LOGICA DE NEGOCIO
    • El cliente solo puede ver su propio historial disciplinario. El Barbero solo visualiza el historial de clientes vinculados a su sede. El Dueño tiene acceso al expediente completo del local.
    • Las sanciones pasadas no se borran del historial; si un Dueño condona una falta, la sanción cambia su estado a "Condonada / Exenta", pero se conserva la traza para métricas futuras.
■ Decisions //DECISIONES
    • Si la fecha actual supera la fecha de expiración de la sanción, el sistema actualizará automáticamente en pantalla el estado del cliente a "Habilitado/Activo", archivando la sanción en el historial de resueltas.

(VERIFICACIÓN DEL ESTADO Y DETALLES DE PENALIZACIÓN)
Steps
1. El Cliente ingresa a la aplicación o plataforma y navega a la sección "Mi Perfil" => "Estado de la Cuenta"
2. El sistema consulta en la base de datos el historial de sanciones y penalizaciones asociadas al ID del usuario.
3. El sistema evalúa el estado de penalización del perfil:
    3.1. if el cliente no posee ninguna penalización o su última sanción se encuentra en estado Expirada:
        3.1.1. El sistema despliega el indicador de cuenta: "Estado: Excelente / Sin Restricciones".
        3.1.2. El sistema muestra el contador acumulado de cancelaciones del mes actual con el aviso: "Puedes realizar reservas de manera normal".
    3.2. else if (El cliente registra una sanción en estado Activo):
        3.2.1. El sistema presenta un banner destacado de advertencia de color rojo/amarillo indicando: "Cuenta Temporalmente Sancionada".
        3.2.2. El sistema despliega el desglose detallado de la sanción: Motivo de la penalización, Fecha de inicio de la sanción, Duración total y Días/Horas restantes para el levantamiento.
        3.2.3. El sistema aclara los impactos operativos: "No podrás agendar nuevas citas hasta el [Fecha exacta de finalización]".
         end if

(CONSULTA DESDE EL INTENTO DE RESERVA / INTERCEPTOR)
Steps
1. El Cliente intenta seleccionar una fecha y hora para agendar una cita en un establecimiento
2. Antes de procesar la reserva, el sistema invoca de forma transparente la consulta del estado de sanción del usuario.
3. El sistema evalúa la condición de la cuenta:
    3.1. if el usuario presenta una sanción activa en el módulo de penalizaciones:
        3.1.1. El sistema frena inmediatamente el flujo de agendamiento y redirige al usuario a la vista del RF42.
        3.1.2. El sistema notifica en pantalla: "No es posible continuar con la reserva. Tu cuenta registra una sanción activa hasta el [Fecha de término]. Consulta los detalles en tu perfil".
    3.2. else if
        3.2.1. El sistema permite al cliente continuar normalmente con el proceso de selección de servicio, profesional y confirmación de cita (RF10).
         end if
