Description

 

El sistema permite al dueño del establecimiento dar de alta un nuevo trabajador o colaborador en la plataforma.

Captura la información personal y laboral del empleado (nombre completo, documento de identidad, teléfono, correo electrónico, foto de perfil, cargo, especialidades y horario asignado) y crea sus credenciales de acceso con rol de Personal.

 REGISTRAR EMPLEADO : Use Case

ESTABLECIMIENTO (DUEÑO)
■ Workflow // FLUJO DE TRABAJO
    • Accede al módulo "Gestión de Personal" y presiona el botón "Registrar Empleado".
    • Completa el formulario con los datos personales, de contacto y perfil profesional del trabajador.
    • Selecciona la sede asignada y marca los servicios que el empleado está capacitado para realizar.
    • Define el horario laboral individual o asigna el horario general del local.
    • Presiona "Guardar / Crear Empleado".
    • El sistema valida los datos, registra la cuenta en la base de datos y envía las credenciales de acceso temporales por correo electrónico al empleado.
■ Business Logic // LOGICA DE NEGOCIO
    • El número de empleados que un establecimiento puede registrar puede estar limitado por el tipo de plan de suscripción activo contratado.
    • El correo electrónico del empleado debe ser único en la base de datos global del sistema.
    • Al registrarse el empleado, el sistema inicializa automáticamente su agenda individual para la asignación de citas
■ Decisions // DECISIONES
    • Si el establecimiento alcanzó el límite máximo de personal permitido por su plan de suscripción actual, el sistema bloqueará el registro y le sugerirá al propietario actualizar su plan

ESTABLECIMIENTO (DUEÑO)
Steps
1. El Dueño de Establecimiento ingresa a su panel administrativo y selecciona la sección "Gestión de Personal" => "Registrar Empleado".
2. Selecciona la sede de trabajo e ingresa los datos del colaborador: Nombre Completo, Tipo y Número de Documento, Teléfono, Correo Electrónico, Especialidad / Cargo y Porcentaje de Comisión o Sueldo.
3. Presiona el botón "Registrar y Enviar Invitación".
4. El sistema evalúa la existencia del correo o documento en la base de datos:
    4.1. if el correo electrónico o número de documento ya está registrado como empleado activo en la misma sede: El sistema frena el proceso y notifica "El colaborador ya se encuentra registrado en esta sede".
    4.2. else if El sistema evalúa los límites de personal contratados en el plan de suscripción actual
        4.2.1. if el número de empleados activos iguala o supera el límite permitido por el plan de suscripción: El sistema bloquea el registro y despliega la alerta "Límite de empleados alcanzado. Actualice su plan de suscripción para vincular más personal".
        4.2.2. else if El sistema genera la cuenta de empleado en estado "Pendiente de Activación", guarda la vinculación en la base de datos y envía una invitación por correo electrónico con un token de acceso seguro.
               end if
         end if
