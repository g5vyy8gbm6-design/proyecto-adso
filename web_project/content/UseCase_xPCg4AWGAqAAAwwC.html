AUTENTICACION Y PERFILES : System

Use Case - MODIFICAR PERFIL link

Properties
Name Value
Description

El sistema permite a cualquier usuario autenticado acceder a la configuración de su cuenta para consultar y actualizar sus datos personales (como nombre, teléfono, fecha de nacimiento o contraseña)      . 

 

El usuario modifica los campos deseados y envía el formulario; el sistema valida el formato de los datos ingresados y guarda los cambios en la base de datos      . En caso de requerir la modificación de credenciales sensibles, se aplican confirmaciones de seguridad adicionales      .

SUPERADMINISTRADOR
■ Workflow // FLUJO DE TRABAJO
    • Accede a la sección de configuración de su perfil administrativo desde el panel principal.
    • Modifica sus datos de contacto institucionales o credenciales de acceso.
    • Guarda los cambios y el sistema confirma la actualización.
■ Business Logic // LOGICA DE NEGOCIO
    • La actualización de credenciales de nivel de Superadministrador invalida las sesiones activas en otros dispositivos por seguridad.
    • Se registra un log de auditoría del cambio realizado.
■ Decisions // DECISIONES
    • Se restringe la edición de ciertos parámetros del rol Superadministrador para mantener la estabilidad del sistema.

ESTABLECIMIENTO (DUEÑO)
■ Workflow // FLUJO DE TRABAJO
    • Accede a su perfil personal dentro de la plataforma de administración.
    • Actualiza datos como teléfono de contacto personal, nombre o contraseña de acceso.
    • Guarda la información y recibe mensaje de confirmación exitosa.
■ Business Logic // LOGICA DE NEGOCIO
    • La modificación del perfil del dueño no altera los datos comerciales del establecimiento (los cuales se gestionan en su respectivo módulo).
■ Decisions // DECISIONES
    • Si modifica el correo electrónico, se solicitará re-autenticación para validar la propiedad de la nueva cuenta.

PERSONAL/PROFESIONAL
■ Workflow // FLUJO DE TRABAJO
    • Ingresa al apartado de perfil dentro de su vista operativa.
        ♦ Actualiza su número de contacto personal, foto de perfil o credencial de acceso.
        ♦ Guarda los cambios aplicados.
■ Business Logic // LOGICA DE NEGOCIO
    • El profesional solo puede editar su información personal; la asignación de horarios y servicios del establecimiento depende del Dueño.
■ Decisions // DECISIONES
    • Se habilita la edición de la clave personal sin requerir intervención del administrador del local.

CLIENTE
■ Workflow // FLUJO DE TRABAJO
    • Ingresa a la sección "Mi Perfil" desde la aplicación o web.
    • Edita campos permitidos como nombre, número telefónico o fecha de nacimiento.
    • Guarda las modificaciones y visualiza la información actualizada.
■ Business Logic // LOGICA DE NEGOCIO
    • Se valida que el número telefónico y formato de datos cumplan las sintaxis requeridas.
■ Decisions // DECISIONES
    • Los cambios en el perfil se reflejan inmediatamente en las futuras reservas del cliente.

SUPERADMINISTRADOR
Steps
1. El Superadministrador accede a "Configuración de Cuenta Administradora".
2. Actualiza sus datos de contacto administrativo y métodos de autenticación de seguridad (2FA/MFA).
3. Presiona "Guardar Configuración".
4. El sistema evalúa los parámetros de seguridad:
    4.1. if los datos requeridos para la verificación en dos pasos son inválidos: El sistema cancela el guardado y mantiene los métodos de seguridad anteriores.
    4.2. else if El sistema actualiza las credenciales y configuraciones en la base de datos global.
         end if

ESTABLECIMIENTO (DUEÑO)
Steps
1. El Dueño de Establecimiento accede al módulo de "Perfil del Negocio".
2. Actualiza la información institucional del local (nombre comercial, teléfono de atención, dirección, redes sociales, logo y fotos de la sede).
3. Presiona el botón "Guardar Información Empresarial".
4. El sistema evalúa la consistencia de los datos:
    4.1. if la dirección o coordenadas de geolocalización no se pueden validar en el mapa: El sistema notifica "Ubicación no encontrada" y solicita ajustar la dirección.
    4.2. else if El sistema actualiza la información en la base de datos y refleja los cambios inmediatamente en el catálogo público de la plataforma.
         end if

PERSONAL/PROFESIONAL
Steps
1. El Personal / Barbero ingresa a "Mi Perfil Profesional" desde su panel de trabajo.
2. Modifica su especialidad, descripción bio, horarios de atención o adjunta fotos a su portafolio de cortes.
3. Presiona el botón "Actualizar Perfil Profesional".
4. El sistema evalúa los datos y archivos ingresados:
    4.1. if la información obligatoria se encuentra incompleta O el formato del horario es inconsistente:
    4.2. else if El sistema guarda los datos en la base de datos, actualiza la ficha pública del profesional dentro del establecimiento y despacha una notificación de éxito.
         end if

CLIENTE
Steps
1. El Cliente accede a la sección "Mi Perfil" en la plataforma web o móvil.
2. Modifica sus datos personales (nombre, teléfono de contacto, foto de perfil).
3. Presiona el botón "Guardar Cambios".
4. El sistema evalúa la validez de los datos ingresados:
    4.1. if el número de teléfono ingresado ya pertenece a otro usuario registrado O los campos obligatorios están vacíos: El sistema detiene la actualización y despliega una alerta indicando el error específico.
    4.2. else if
        4.2.1. if el usuario cargó una nueva imagen de perfil: El sistema valida que el formato (JPG/PNG) y peso de la imagen (máximo 2 MB) sean correctos.
            4.2.1.1. if la imagen no cumple con los formatos o límites de peso: El sistema rechaza la imagen y mantiene la foto anterior.
            4.2.1.2. else if El sistema sube la imagen al servidor, actualiza la ruta y guarda los datos en la base de datos.
                4.2.1.2.1. El sistema actualiza los registros en la base de datos, refresca la sesión del usuario y muestra un mensaje de confirmación.
                     end if
               end if
         end if
