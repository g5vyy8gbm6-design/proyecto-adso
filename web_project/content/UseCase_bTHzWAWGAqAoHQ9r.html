El sistema despliega la ficha detallada de la ubicación física de un establecimiento seleccionado.

Muestra la dirección exacta, el municipio, la ciudad, las indicaciones o puntos de referencia, e integra un acceso directo que redirige a aplicaciones externas de navegación para trazar la ruta punto a punto

INFO DE UBICACION
■ Workflow //FLUJO DE TRABAJO
    • Ingresa al perfil de un establecimiento desde la lista de búsqueda o la vista de mapa.
    • Selecciona el apartado o pestaña "Ubicación / Cómo llegar".
    • El sistema consulta la base de datos y despliega la dirección completa, la ciudad, las observaciones de acceso y el mapa en miniatura.
    • Opcionalmente, el usuario hace clic en "Abrir en aplicación de mapas" (Google Maps / Waze).
    • El sistema transfiere las coordenadas hacia la aplicación externa del dispositivo.
■ Business Logic //LOGICA DE NEGOCIO
    • La dirección devuelta corresponde estrictamente a la sede física configurada y validada por el dueño del local en el módulo de administración.
    • Los accesos de navegación externa generan una URL con los parámetros de coordenadas exactas (latitud/longitud) para garantizar un trazado preciso.
■ Decisions //DECISIONES
    • Si el establecimiento opera bajo modalidad únicamente a domicilio, este caso de uso mostrará la zona/cobertura de atención autorizada en lugar de una dirección física abierta.

INFORMACION DE ESTABLECIMIENTO
Steps
1. El Cliente hace clic sobre la tarjeta o pin de un establecimiento desde la lista de búsqueda, la vista en mapa o la búsqueda cercana.
2. El sistema consulta la base de datos recuperando la información completa del expediente del negocio.
3. El sistema evalúa el estado actual del establecimiento:
    3.1. if el establecimiento se encuentra en estado Inactivo, Suspendido o Cancelado:El sistema frena el acceso a la ficha y despliega el mensaje "El establecimiento seleccionado no está disponible en este momento".
    3.2. else if (Establecimiento en estado Activo):
        3.2.1. El sistema carga y presenta la vista detallada estructurada en secciones:
        3.2.2. Encabezado: Nombre comercial, Logo, Banner/Foto de portada, Dirección, Teléfono, Redes sociales y Calificación promedio con total de opiniones .
        3.2.3. Horarios de Atención: Horarios por día de la semana e indicador visual ("Abierto ahora" / "Cerrado").
        3.2.4. Pestaña de Servicios: Lista completa de cortes/tratamientos con duración y precios.
        3.2.5. Pestaña de Barberos/Personal: Fotos, nombres y calificaciones individuales del equipo de trabajo.
        3.2.6. Pestaña de Reseñas: Lista de valoraciones hechas por otros clientes con sus respectivos comentarios y respuestas del dueño.
        3.2.7. Botón de Acción Principal: Acceso directo a la consulta de disponibilidad para agendar citas.
         end if
